# unisacc v0.0.13 计划（草案，2026-09-29 归集；开工前再细化）

> 来源：dsh 提案（决策完备性主图 + 3 条配套）与 0.0.12 进行中的顺延项。原则同 0.0.12：每项有判据、私有候选、受影响门禁、根产物、回执。

| 项 | 内容 | 判据 |
|---|---|---|
| R13-1 决策完备性（论文主图） | ① `unisa docs` 产出“每 stage 决策域大小（key 全域格数，合计 20,374）+ 验证方式（全域逐格双向 `inf()`==`infer()`，DENSE 查表）”的生成表进 prd/论文 §5.3；② 决策代码行数账本升级为 **T-2 完成度**：表形状决策点（`inf()`/`infer()` 调用处，当前 31：back_lower 16 / front_parse 9 / opt 4 / front_pp 2）全部走网络 = 31/31；口径明确**不是**神经化覆盖率的分母（T-1 的走查器/符号表/重定位/镜像头是经典代码，不得神经化）；③ 论文主张改写：“编译器全部决策空间有界且逐格穷举验证表==网”，与 Boniol 等的等价性工作区分（完备性 vs 等价性），并预备“域太小”的回答（编译器全部决策空间，随 stage 线性增长） | 表由生成器产出且 docs.sh 校验；账本两版数据；论文中英同步 |
| R13-2 六目标零 #ifdef 门禁化 | 扫描 src/ 与 exec/：目标相关条件分支只允许出现在 abi/isel/enc 三个 stage 的**声明**里；**边界裁定**：宿主层文件（自举宿主依赖：`src/host_dl.h`、`exec/c/asm/*.S`、libunisacc 宿主适配、Windows 导入表）以白名单文件登记，允许 `__APPLE__/_WIN32/__UNISA__` 等宿主条件；白名单外出现即红 | 门禁一次全绿；白名单每项写明“宿主依赖”理由 |
| R13-3 FX-6 作为 T-4 实证 | 承接 R12-5 ④：无论 int32+SIMD 是否达标，结论进论文（达标=提速证据；不达标=负结果），证明“换权重表示不动 kernel 语义” | 回执含逐字节同输出 + 计时 + 论文段落位置 |
| R13-4 0.0.12 顺延承接 | BANK 余片（AAPCS64/Win64、入站）、Windows SEH 若未闭合、us_eval/us_reload、网络裁判登记余项、FX-5 分层 libc（12 探针后决定） | 各项按 0.0.12 回执的“未做”逐条销 |

**明确不做**：扩大神经化到 .S / back_encode（违反 T-1，毁掉穷举验证）；体积主张；T2 全走查器机器证明（0.1.x）。
