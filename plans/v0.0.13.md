## 任务树（2026-09-30，政委要求；节点写目标 / 验收 / 依赖 / 顺序；阻断项最前）

约定：**红例**=一份能在 v0.0.12 正式版（未签候选 df8cc9b4，与签后 fb607af5 同源）上复现失败的最小源；**转绿**=红例通过且从对应 knownfail 删行（清单里的探针一旦通过而未删行，套件即红）。三个套件：
- `difftest`（`tests/c/*.c`，单文件、一次编译一次运行、与宿主 cc 对拍；现在同时驱动 Python 参考与产品 `com-difftest-$shard`；清单 `tests/difftest.knownfail`（参考）/`tests/difftest.com.knownfail`（产品））；
- `c99`（`tests/c99/*.c` + `c99.knownfail`，语言特性覆盖）；
- **新：`fb12-multi`**（`tests/fb12/NN-*/` 目录夹具：多源文件、-I 目录、多次运行或带参数；每目录一个 `cmd`（命令行，`$UC` 代产品）、`expect.txt`（期望 stdout）、`expect.rc`；驱动 `tests/fb12multi.sh`，清单 `tests/fb12.knownfail`，同一契约；有界 ≤55 s，产品驱动 `MODEL_COM`）。放不进单文件 difftest 的条目归它：**22**（多个 -I）、**24**（预处理，需目录/多文件触发）、**27**（多单元容量：w1..w30）、**28**（多单元 static 匿名 struct）、**30**（多单元标签命名）、**fb12-03 第二路径**（带参数运行应触发断言，期望 rc 1 + `assertion failed: argc == 1`）。**31** 单文件即可复现，归 difftest。目录夹具的命令拆成 `build` 与 `run` 两步（dsh 实测：`$UC … && ./prog` 会把“编译器拒绝 rc 1”与“程序返回 1”混同）。本套件需要可执行产品，故只在 `gate.sh --list --com` 中出现。**编号口径**：R13-0b 为 28 个编号（07、08、08b、09–15、15b、16、17、17b、18–31）；红例文件数以三份 knownfail 清单为准。
