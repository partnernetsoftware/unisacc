# Moving from m4 to flownet

m4 (`m4/`, Python) proved the arc gold -> integer net -> flows -> bytes on the ujs -> `\0asm` path, byte for byte
against the ujs gold path. flownet (`flownet/`, `.cx`) is the same paradigm as a module that knows no language: m4's
ujs knowledge moved out to a boundary adapter (`adapter/ujswasm/`), and a second consumer (`tests/tdescprobe.cx`, a
different domain) uses the same module. This page says where each part of m4 went, how to move a consumer over, what
is known to differ, and what the coverage is. The requirement is `plans/m4-flownet-cx-module.md`; the API is
`flownet/API.md` (CXIF v1, W6 B2; until it lands, the header comment of `flownet/api.cx`), with `flownet/README.md`
as the overview.

Terms follow `prd.md` section 0 and `docs/glossary.md`: a **flow** is a byte-pipeline segment of a consumer's run
(m4's flows are lex, front, select, encode; tdescprobe's are declare, context, size); a **net** is a finite decision
table built as an integer net. The number of m4's flows (4) and the number of nets that decided in m4 (4) are
different counts that happen to be equal.

## Where each part of m4 went

| m4 (Python) | flownet (`.cx`) | notes |
|---|---|---|
| `m4/contract.py`: NETS, FLOWS, RESERVED, OBSERVED, ISEL_CHOICE | the consumer's `contract.tsv` (rows `net`, `flow`, `reserved`, `observed`, `choice`, `phase`), read by `flownet/contract.cx`; for ujs, `adapter/ujswasm/tables/contract.tsv`, generated by `adapter/ujswasm/tables.cx` | the contract is data the consumer owns; flownet checks it partitions the nets |
| `m4/nets.py`: IntNets from `ujs.seed.construct.gold.STAGES` | `flownet/nets.cx`: an integer net read from `NET.net.tsv`, or constructed from gold (`fn_build`, `fn_construct`), exact by construction; gold from a label source the consumer injects (`fn_label_source`) | for ujs the label source is `adapter/ujswasm/ujsgold.cx`, a `.cx` port of the ujs gold |
| `m4/flows.py`: `run` (compile, check the trace, emit), `_check_trace` | `flownet/flow.cx` behind `fn_run(FLOWS, FCTX, EMIT, ECTX)`: books reset, the consumer's flows run, trace checked (no gold fallback), then the emit hook once | `fn_expect` (pinned books) and the `FLOWNET_SWEEP` test hook are new: m4 had neither |
| `m4/emit.py`: isel dispatch, enc gate, WAT text, wat2wasm | `adapter/ujswasm/ujswasm.cx`: the select and encode flows write the WAT with `fn_out`; the emit hook runs wat2wasm | ujs-specific, so it stays at the boundary, not in flownet |
| ujs front end (`front/compile.py`), called by m4 | ported into `adapter/ujswasm/ujswasm.cx` (lex and front flows); every decision is an `fn_ask` | W4: type, shape and ic answers are consumed (legal or refused), no longer only observed |
| `Oracle(drive="gold")` | `fn_drive("gold")` | a reference mode only: any gold fallback fails the trace check |
| CLI `acc` | `fn_acc` per net; the adapter's `check` reports acc 10/10 | |
| CLI `build SRC -o OUT` | `sh ./unisacc.com -run adapter/ujswasm/ujswasm.cx -- build SRC -o OUT [--wat FILE]` | refusals have the D5 shape (below) |
| CLI `check` (corpus vs the ujs gold path) | the adapter's `check` against the W1 record `tests/flownet-baseline.tsv` | no Python |
| CLI `selftest` (does each net decide?) | the adapter's `selftest ROOT K/4` (lying label sources, nets built with `fn_build`) | EXPECT_W4 = m4's EXPECT plus type/shape/ic |
| `tests/m4.sh` | the `flownet-*` jobs of `tests/gate.sh` | each bounded at 58 s |

m4 itself is unchanged and stays the measurement oracle: `tests/flownetbaseline.cx` (W1), the adapter's `accepts`
and `oracle` commands, and `tests/flownetw5.cx oracle` run the m4 package as a child process. Nothing under
`flownet/` runs or names Python (D1, red line 3).

## Moving a consumer

1. **Contract.** Write `contract.tsv` in the consumer's own directory (never under `flownet/`, which holds mechanism
   only and is guarded by `flownet-w6-b1`): the nets, each flow with the nets it asks, reserved and observed nets,
   choices, and the book phases in order.
2. **Gold.** Either gold tables `NET.gold.tsv` beside the contract, or a label source in code: a domain function
   (the field rows and the class row of each net) and a label function (one class per key), injected with
   `fn_label_source`. flownet asks each key once, at construction.
3. **Nets.** `fn_construct(DIR)` (contract and gold from DIR or the label source, nets constructed), `fn_build(TEXT)`
   (contract as text, gold from the label source), or `fn_open(DIR)` (prebuilt `NET.net.tsv`). Check `fn_acc`.
4. **Flows.** One function that runs the consumer's work: `fn_phase` at each book phase, `fn_ask*` for every
   decision (never answer a net's question locally), `fn_gate` where only some answers are legal, `fn_choice` for
   alternatives, and `fn_out` for the result.
5. **Emit hook.** What to do with the whole output; it can refuse (judge the output against a reference).
6. **Run.** `fn_run(flows, fctx, emit, ectx)`; on -1 print `fn_error()` and exit 1 (the D5 shape).
7. **Prove it.** Parity with the old path (bytes and books), acc on every key, the D5 shape on every refusal, and
   the mutations: with the flownet calls removed the consumer's gate must be red (D3); pin the books (`fn_expect`);
   run the sweep (`FLOWNET_SWEEP=all`) and compare its per-perturbation rows with a record the consumer's gate keeps
   (W3 fix 4), so an answer that never reaches the output is caught key by key.

The D5 shape of a refusal: exit status 1, stdout empty, no output file (an old one removed), and one stderr line
naming the input, the reason and, where there is one, the position (`SRC:LINE`, a function and instruction, or the
generated WAT's line:col).

## Known differences from m4 (measured, all named refusals, never silent)

- Non-ASCII outside string literals: only the Latin, Greek, Cyrillic, CJK and Hangul letter ranges are covered;
  other code points are refused by name (Python's whole isalpha table is not ported).
- f64 literals reach wat2wasm as normalised decimal text (same value, same bytes; not Python's repr spelling).
- A float literal that rounds to infinity is refused by flownet; m4 writes `f64.const inf` and accepts it. Integer
  literals above 2^64-1 are refused at their line (wat2wasm would reject them).
- wat2wasm failures become one line: no ANSI colour, no scratch path, the first `error:` with its WAT line:col; when
  wat2wasm dies without an error line (W5), the line names how it died and the WAT's size and nesting depth.
- type, shape and ic decide (legal or refused) since W4; scope, irsel and reloc stay RESERVED (unreachable without
  changing the ujs front end, ruling 4; `research/flownet-w4-decisions.md`).

## Coverage (W5)

The corpus grew from the 28 programs of `tests/ujs2wasm/corpus` to every ujs program in the repository, recorded in
`tests/flownet-coverage.tsv` in three states (red line 2). Measured 2026-10-23:

| state | class | programs | meaning |
|---|---|---|---|
| covered | byte-identical | 39 | flownet's `\0asm` equals the m4 oracle's: the 28 corpus programs, the 5 m4 probes, the step corpus program `setidx_globals.ujs`, and the 5 programs of `tests/ujs2wasm/neg` that ujs and m4 accept (`dict_key9`, `str_escape`, `str_lit256`, `str_nonascii`, `str_nul`) |
| refused | front | 4 | outside the language, refused by both before any WAT: `bad_expr`, `bad_fn`, `bad_lex`, `m4/neg/dict_set_bad_target` (flownet names the line; m4 raises CompileError or SyntaxError) |
| refused | assembler | 4 | the flows pass and the WAT is byte-identical to the one m4 hands to wat2wasm, but wat2wasm (wabt.js 1.0.39 on this host) dies with `RuntimeError: memory access out of bounds`, for m4 as for flownet: `ujs/practice/web/game/drone.ujs`, `sim.ujs`, `monopoly.ujs`, `ujs/iterate/compiler.ujs`. Their WAT nests 264, 465, 804 and 14635 levels deep; no covered program's WAT nests deeper than 58. Not a flownet gap: the external assembler |
| refused | gap | 0 | flownet refuses what m4 builds |
| untested | embedded | 24 | the programs embedded as `"src"` strings in `ujs/practice/{core,web}/{demos,full_demos}.json`: not built, each matched (blanks dropped) to a covered twin in the corpus |
| untested | no-oracle-verdict | 0 | a program with no reference verdict yet |

Also listed: 1 alias (`ujs/practice/core/compiler.ujs`, a link to `ujs/iterate/compiler.ujs`). Not in the set: the
`.js` files under `ujs/` (JavaScript, not ujs) and the other consumer's inputs (tdescprobe's 106 declarators are
covered by its own gates). Never a state, always red: flownet building bytes that differ from the oracle's, flownet
building what the oracle refuses, or flownet refusing at wat2wasm with a WAT other than the oracle's.

The reference verdict comes from the W1 baseline where it has one (37 programs; re-measured by
`flownet-baseline-out1..4` and `flownet-baseline-check`), else from the m4 oracle through the adapter's `oracle`
command (10 programs; re-measured by `flownet-w5-oracle`). Commands, from the repository root:

```
sh ./unisacc.com -run tests/flownetw5.cx -- cover .     # gate flownet-w5-cover: no Python, about 30 s
sh ./unisacc.com -run tests/flownetw5.cx -- oracle .    # gate flownet-w5-oracle: the m4 oracle as a child, about 35 s
sh ./unisacc.com -run tests/flownetw5.cx -- write .     # re-record after a deliberate change (oracle included, about 45 s)
sh ./unisacc.com -run tests/flownetw5.cx -- selftest    # the classifier on seeded cases
```

A new `.ujs` file anywhere in the repository makes `cover` red (it is untested and the record does not list it)
until the record is rewritten, so the coverage cannot silently shrink back to the corpus.
