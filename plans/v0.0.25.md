# v0.0.25 动态计划（随做随改）

规则沿用 0.0.24：梳理、开工、动态计划同时进行；一项最多顺延两次；版本号提交之后进入封版冻结窗口，只收修红的改动。

基线：0.0.24 已公开（2026-10-04，签名 sha256 dca05a96…，候选 518601e5，rc/v0.0.24 → 1801e170；收口记录见 [archive/plans/v0.0.24.md](../archive/plans/v0.0.24.md)）。

**范围（政委 2026-10-04）**：0.0.24 用了 8h22m，开发占三分之二。本版控制范围：产品侧主线只放 T1e 和 T2 两项给 cdx；cc 这边先做流程项 P1–P7 和 X7，D2、N1 只做评估或参考侧，不追产品。能并行的都切给 cdx，cdx 交付当轮就提交，提交时顺手派下一件活（P6）。复盘全文：[research/r24-pipeline-retro.md](../research/r24-pipeline-retro.md)。
