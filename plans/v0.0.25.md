## 自举路线（主人 2026-10-04：能用上一版 unisacc.com 做的就不用 Python，要快点走上自举）

**来源**：主人在 cc-unisacc 会话里的原话（“能用 unisacc.com（上一版）自己做的情况下就不太应该用 python，除非能力未适配”“比较心急希望快点走上自举的路”），**政委 2026-10-04 21:31 确认**：0.0.25 提前走自举，B1–B5 照计划做，包括本版启动 gen.py 的 C 版；原“种子层 C 重写放到 0.0.25 之后评估”的口径作废。

**原则**：新写的工具优先用 C 写，用上一版 unisacc.com 编译和运行；只有 unisacc.com 能力不够时才用 Python，并把缺的能力登记成缺口。Python 构造路径保留为独立参考，直到 C 路径全域字节一致。模板迁移（T1e）是清债，不算种子自举。
