## 发布说明素材中的 D2 已知缺口

(1) 经函数 typedef 指针调用并读取返回值仍可能报告 `not covered: invalid return-type source category`。`typedef int F(int); void h(F);` 和等价的显式函数指针定义仍可能不兼容。无原型 `typedef int F();` 配 `(int)` 也有同类限制。调用时可先改用显式函数指针形参，核对运行结果。

(2) 双层括号形参名 `void f(int ((a)));`、`void f(void ((cb))(int));` 以及两种 K&R 定义仍有合法样本被拒。裸 `void` 即使在名称外加括号也须单独且无名，`void f(void (cb));` 继续拒绝。

(3) `int f(int);` 和 `int f(){return 0;}` 以两种顺序并列时仍被接受。函数 typedef 直接声明后，返回类型或形参冲突的定义也可能被接受。函数返回函数、函数类型数组元素及结构成员的错误用法仍有漏诊。这些样本在本次修复前后的判定相同。独立对照清单见 `~/.claude/jobs/2798e440/tmp/gatekeeper-d2-p2.md`。

(4) 四类声明不一致现在会报告带文件、行、列的告警。默认模式继续生成对象，使用 `-Werror` 时按既有告警合同汇总后拒绝，且无对象产出。方括号中的 `-Wd2-*` 是诊断标识，暂不支持作为 `-Wno-*` 或 `-Werror=*` 的参数。全仓命中数待消费者清扫完成后入账。
