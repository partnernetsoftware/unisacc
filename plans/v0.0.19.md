## 条目

- **R19-1 网络头**：来源同 0.0.18 R18-10（dsh 的 C99 harness 要做 LLM 调用的 HTTP/SSE，这是 harness 的心脏）。lnx/osx 走系统调用；`getaddrinfo` 没有 libc 可借，先做数字地址与 `/etc/hosts`，DNS 解析单列（最小 UDP 查询或明确不支持），不冒充完整解析器；win 走 Winsock（WSAStartup/socket/connect…），是独立的一列。**不做 TLS**：HTTPS 需要的 TLS 不在编译器随带库的范围，dsh 侧用本地代理或明文端点验收，写进 README 限制表。验收：一个回环 HTTP 往返在三 OS 上运行，与 gcc 编译的同一程序输出一致；dsh 的探针进 tests/c。
