## 与标签同名的 heads/v0.1.x

同名且指向不同提交, `git rev-parse v0.1.x` 会报 ambiguous:

| 名字 | heads | tags |
|---|---|---|
| v0.1.0 | 7dc318425 | a11d28fc0 |
| v0.1.1 | 7b49a9e47 | b3e9731b6 |
| v0.1.2 | a7ae7a494 | 115e5720d |
| v0.1.3 | 88e7e3210 | f485ec9a2 |
| v0.1.5 | a03168fa9 | ba12b08df |

v0.1.4 只有 heads `162464475`, 没有标签, 现在不歧义. v0.1.6 `e0bfac5a1` 与 v0.1.7 `acad02543` 还没有标签. 打标签之后会歧义, 同样改名.

不要删标签. 不要 `branch -D`. 工作树还占着这条分支时不能改名. 顺序是先摘工作树, 再改名, 提交还在:

```
git worktree remove .claude/worktrees/v0.1.5
git branch -m v0.1.5 archive/v0.1.5
git branch -m v0.1.0 archive/v0.1.0
git branch -m v0.1.1 archive/v0.1.1
git branch -m v0.1.2 archive/v0.1.2
git branch -m v0.1.3 archive/v0.1.3
git branch -m v0.1.4 archive/v0.1.4
```

v0.1.6 与 v0.1.7 的工作树还在时不要改名. 远程 `origin/v0.1.0` 到 `origin/v0.1.5` 不在这份清单里删. 删远程要另一次授权.

改名后核:

```
git rev-parse v0.1.5
```

应只打出标签 `ba12b08dfddefea5a5e9241f095ede4e7f83473d`, 没有 ambiguous 警告.
