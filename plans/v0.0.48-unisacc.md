# unisacc 0.0.48 计划(草案,cc 前瞻评估,2026-11-07;0.0.47 进行中,本文随其结果修订)

## 主题:可资格、可分发、可自证
0.0.46 证明六目标原生能跑;0.0.47 把「可信」(合法 C99 不误拒、非法 C99 不静默接受)推进;0.0.48 要解决的是剩下三类「说不满」的地方:
1. **全批资格**:0.0.46 全批未达资格(230 PASS / 27 FAIL / 4 UNKNOWN / 162 NOT-AVAIL / 20 KNOWN-GAP),0.0.48 目标是第一个**全批可资格**的版本。
2. **分发体验**:陌生用户从 Release 到 hello 的路径、Windows 原生运行、PATH 安装、最低 OS、CI pin 写法。
3. **自证与信任基**:Windows/macOS 原生自举、Python 构造协调器、host C 引导这些「未声称」项,至少把可测的推进一格。

## 需要主人的决策(越早越好)
1. **是否支持 GNU/C11 扩展**(N10):不支持则外部语料口径固定为「C99 严格」。
2. **`-c -b osx/*|win/*` 行为**:真拒绝(文档与断言一致,倾向) vs 改文档并放行(会降低断言强度,需主人批准)。
3. **0.0.48 是否把 TAPE-END 单独成版**:若 0.0.47 的 S1 工作量过大,按候选时间表决策点拆到 0.0.48,则 N2 前移为主线。
4. **Windows 原生自举是否进入 0.0.48 目标**(N8 只做可测实验,不承诺宣称)。
