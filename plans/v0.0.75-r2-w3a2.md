# v0.0.75 R2 W3a2:-funit 对象进程槽具名化(定位与设计,停手不硬做)

输入身份:分支 v0.0.75 头 a045a0811f;已装产品 ./unisacc.com(共享检出符号链接);闭包 rtclosure-987c54b4(27408 字节,tools/closure-obj.cx build 现编)。证据 release/evidence/v0.0.75-r2-w3a2-2026-11-18.tsv。

## (1) 定位

- 进程槽不在头文件:include/stdlib.h 的 _unisa_environ_init 调内建 __argc()/__argv(),内建降低为读"进程区"两格;_start 由降低表 exec/lower/code-entry-result.tsv(posix C.processargs 行,`argsave` 文本,整程序路 offset 48)写入,对象由 exec/enc/objectplan + elfobject 表网写出,关系符号只有节符号 .bss。
- 实测布局不变量:每个 -funit 对象的进程区是 .bss 尾部固定块,argc 在 bss_end-0x78、argv 在 bss_end-0x70(h.o bss 0x80b2 -> 0x803a;闭包 0x11400 -> 0x11388;u.o 0x490 -> 0x418;a.o 0xa8 -> 0x30),全以 .bss+off 匿名重定位。
- 整程序路的"合并":不是链接时合并,而是 drivelink 把各单元 tape 拼成一条再统一降低,进程区只分配一次(offset 48),天然唯一。

## (2) 私有原型(只在 $CLAUDE_JOB_DIR/tmp/w3a2/p/objlink.cx,不入库)

objlink 侧按不变量把落在 [bss_end-0x78, bss_end-0x68) 的 .bss 重定位改指 _start 所在对象的同一格。结果:hello 加闭包运行输出与 rc(3)与整程序路逐字节相同(9 处改指)。4 源加闭包失败(rc 205、u1 结果为垃圾、strlen 恒 6)。

## (3) 新暴露的两处产出端缺陷(原型证伪"只缺名字")

(a) 无 main 的 -funit 单元把进程入口序言(mov (%rsp) -> argc 格、lea 8(%rsp) -> argv 格)内联进第一个函数(a.o 的 u1、c.o 的 strlen 偏移 0 处),调用时把返回地址写进 argc 格。整程序路只有一个入口所以无此问题;exec/facts/lower-librarymodule.tsv 写明模块降低才关掉"首函数进程设置",-funit 未走这条。槽一旦合并,此序言会污染全程序的 argc/argv,所以合并前必须先关掉。hello 能过只因闭包首函数未在 environ_init 之后被调用。
(b) RT_EXTERN 下 stdlib.h 的暂定定义 `char **_unisa_env;` 在用户对象里成强定义(不出 COMMON),与闭包重复,objlink rc 4 拒绝(b.c 调 getenv 实测)。

## (4) 方案与链接语义

- 槽名:_unisa_proc_argc、_unisa_proc_argv(8 字节,对齐 8)。
- 语义选 COMMON(SHN_COMMON):每个对象都引用、无人"拥有";系统 ld 合并 COMMON,objlink 加 COMMON 合并(取最大尺寸、放 bss)约 30 行。弱定义在系统 ld 下也可用,但"首个弱定义胜出"依赖输入顺序,不选;"闭包强定义、其余 extern"要求闭包永远在场,与 hello 无闭包的整程序对拍不对称,不选。
- 重定位须改成 symbol+addend(不再 .bss+off),系统 ld 才能解析;(b) 同样走 COMMON。
- 整程序路(无 -funit)不出这些符号、不改布局,字节应不变;须在开关 cli/funit 下分支。

## (5) 判断:本单不做,拆三单

改面:objectplan/elfobject 表网(符号与重定位改为具名,x86 与 arm 两个子表,osx/win unitcontainer 也受同一事实约束)、code-entry 降低(-funit 非入口单元关首函数序言)、暂定定义出 COMMON、objlink 收 COMMON。表网改动须"事实表 -> 生成器 -> 表"并重建开发产品,超出"不超过两张单、50 分钟"上限,按简报停手。

工单:W3a2-1 降低:-funit 且单元无 main 时不发进程入口序言(写域 exec/lower 事实与生成器);W3a2-2 对象表网:进程槽与暂定定义出 SHN_COMMON 具名符号与具名重定位(写域 exec/enc objectplan/elfobject 事实与生成器);W3a2-3 objlink 收 COMMON(写域 src/objlink.cx)。验收共同:无 -funit 的 -o 产物至少 10 份真实源 sha256 改前改后相同;4 源加闭包与 hello 加闭包运行输出与 rc 与整程序路逐字节相同;系统 ld 链同组对象同样通过。
