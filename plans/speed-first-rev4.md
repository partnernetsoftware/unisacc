### 授租合同

(1) 一个宿主上的参与实例共用一个资源预算和一个仲裁者。请求声明作业、优先级、截止、三种资源及读写域。CPU 以千分核计，取第一期有效上限，预留一核给系统和短门；短门可动用预留中的可用份额。内存以 MiB 计，取 MemAvailable 与祖先有限的 memory.max 减 current 的最小值，扣安全余量。IO 按实际块设备分池，以一秒内可持续读写字节分别计额，同时限制在途数；由同设备低压窗口历史标定，用 io.stat 与 IO PSI 核实。设备无法归属或基准缺失时，该类作业沿 Q-10 运行。按批定义、目标、冷暖与材料身份分桶，用完成样本的 CPU、峰值 RSS 与读写量 p95 估算；不足五例只观测。每次只扣外部实占与各存活租约的估计或实占较大者，核算内存余量时只再扣尚未兑现的承诺。过期或不明样本不扩容。

(2) 工作树按真实路径与 Git common-dir/ref 定位，候选按 APE 摘要与产物目录定位，harness 按闭包、布局与证据文件定位。对共享输出再按实际文件或目录加写域，防止路径别名、不同摘要写同一位置。按稳定次序一次原子核三种资源及全部域，共享读、独占写，等待者不占部分资源。dvqualify 的证据写锁、原 jobs 上限、原批次截止继续生效；同一 TSV 始终只有一个写者。多设备或子作业从父租约预算中划拨。

(3) 提交门、发布校验优先，普通实跑其次，S0 推测预制最后。短门等待时暂停向长批发新工作，在下一批或链相完成且证据可读回时让出租约。已起的不可切分批在原窗内结束；原窗耗尽记 UNKNOWN，续跑只补该批。CAS、推送、证据落盘与写锁临界区必须完成。推测作业可撤销自有进程组并丢弃未发布代；已落盘的同身份产物仍须复核。恢复前核候选、读集、材料、harness 与检查点；身份有变按原入口重跑。普通队列按等待时间提升优先级，同级 FIFO，已超截止具名退出；影子记录长批最长等待，连续三次让位后为其保留下一个可容纳的窗口。

(4) 租约含单调时钟截止、实例代、boot_id、持有者 PID 与启动身份。建议每 5 秒续心跳、15 秒失联进入对账，续租不能延长作业硬截止。到期先核进程树和写锁，确认退出才归还；重启按持久租约与内核实况重建保留量，旧代不可续签。仲裁者有界自退，最长 7200 秒。服务或采样不可用即停发新租，用旧 Q-10 与原锁继续无冲突工作；存活且归属未明的域等原截止，未决记 UNKNOWN。关闭实际授租时先排空或对账存量。任何路径均不能把 PREPARED 写成批次结论。

### 对拍、放行与依赖

第一步另设默认关闭的建议开关，每次 Q-10 原判独立运行，记录建议授租与实际起跑的四格交叉表。devsvc events 按请求与租约 ID 写 request、would-admit/wait、grant、yield、resume、expire、release、fallback；带单调时刻、版本/实例代、输入身份、三域及模式、资源估计/实占、理由、截止与原 Q-10 判定。心跳合并，队列有界；丢事件按计数报缺失，该轮不可作放行依据。只开建议时同一批 RAW、rc、起跑数需与关闭时一致。
