## 一、范围(5 项必做,可选项移入候选池)

1. **Z1a `sy_child_subreaper` 下沉核心**:
   - `prctl` 调用号(lnx x86_64=157、arm64=167)与 `PR_SET_CHILD_SUBREAPER=36` 入 `exec/facts/sys-syscalls.tsv`,经 `tools/target-gen.cx` 生成 `cx/sys/sysnums.cx`,实现落 `cx/sys/posix.cx`;
   - `ext/sysx/reaper.cx` 去 `dock`(删 263-266 行裸 `__syscall6` 与平台 `#if`);
   - osx/win 具名拒绝 `-ENOSYS`(建议复用 `cap=proc-tree`,不扩词表);
   - 验收:现有 `tools/check-reaper.cx` + 新建 `tools/check-l0-subreaper.cx`(lnx 返回 0 且孤儿孙进程可被 wait、表内 osx/win 号为 0 返回 `-ENOSYS`、变异改错号即红)。
2. **Z1b 停止信号常量**:
   - `SIGCHLD`/`SIGCONT`/`SIGSTOP`(及可选 `SIGTSTP`)入 `exec/facts/signal-targets.tsv`,经 `tools/signal-targets-gen.cx` 生成 `include/signal.h`(lnx `SIGSTOP=19`、osx `SIGSTOP=17`;win 停止信号表达法待裁),可能补 `cx/sys/sig.cx` 名表;
   - `ext/sysx/reaper.cx` 去掉 `SY_KT_STOP` 平台 `#if`(43-47 行);
   - 验收:现有 `check-signal-targets.cx`、`check-signal-targets-part.cx` 与 `reaper.cx` 无 `#if` 断言。
3. **Z2 `chown`/`fchmod`/`umask`/`pipe2` 核心 POSIX 接口补齐**:
   - 调用号入 `exec/facts/sys-syscalls.tsv` 生成 `cx/sys/sysnums.cx`(arm64 无 `chown` 号统一走 `fchownat(AT_FDCWD)`;osx 无 `pipe2` 在 `_os` 帮手用 `pipe` 加 `fcntl` 非原子并注释写明;win 具名拒绝 `-ENOSYS` 或沿现有 `syp_pipe_os`);
   - 实现落 `cx/sys/posix.cx`、`cx/sys/proc.cx`(`sy_pipe2` 挨 `sy_pipe`)、可能 `cx/sys/fs.cx`;
   - 验收:新建 `tools/check-l0-posix2.cx`(`fchmod` 后 stat 位相等、`umask` 往返、`pipe2` 两端 `CLOEXEC` 置位且 exec 后子进程不可见、`chown` 非 root 改他人属主得 `-EPERM`/改自身 uid/gid 得 0、win 号 0 得 `-ENOSYS`)。
4. **Z3 双管捕获 `sy_proc_capture`(原 0.0.88 Y7b 顺延)**:
   - 实现落 `cx/sys/proc.cx`(不加新调用号;win 首版具名拒绝);
   - **前置设计待定**:与 `build/std-surface.tsv:128` 现有 `ext.procx` `np_exec` 功能重叠,开工前须先裁定谁是实体谁是封装;
   - 验收:新建 `tools/check-l0-capture.cx`(两路各自完整、超 cap 得 `-EMSGSIZE` 并杀子、截止到期 `-ETIMEDOUT`、子进程写满一路不死锁、无残留 fd)。
5. **Z4 `strtol`/`strtoul`/`strtod` 对接实体回迁 `cx/text` + `(a) sy_now_ms` 头注释补记**:
   - Z4:`cx/text/num.cx`(由软链改为实体并持 `dock`)与 `ext/textx/num.cx`(去 `dock`);与 `0.0.91` Z5(删 `cx/text` 四链接)碰同一文件,**顺序须 `0.0.91` 先完成**;验收 `check-cx-text-new-a`、`check-ext-dock`、`layer-api --check`。
   - `(a)` 注释补记(A 类清单):`cx/sys/time.cx`(15-17 行)中 `sy_now_ms()` 函数头注释写明单调时钟任意原点、仅可做差值不得持久化或跨进程比较,持久化时间戳用 `sy_wall_s()`;验收产品字节等价(注释改 SID 不改字节)。
- **明确不进本版**:
  - 原可选项 `statvfs`、信号掩码、`alarm`:因 `statvfs` 结构布局逐目标不同、信号掩码动 `sig.cx` 跳板区且均需 osx 号核对,全部移入候选池。
