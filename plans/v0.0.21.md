# unisacc v0.0.21 计划（范围草案，2026-10-01）

基线以 v0.0.20 实际验收为准。本计划承接其超量范围；凡在 0.0.19 已顺延、又从 0.0.20 移出的条目，旧版本承诺明确降级，在本版按下表重新立项，不把排期修改算成实现。发布前仍须本地完整门禁与平台证据。

| 顺序 | 新验收单元 | 来源 | 前置条件 |
|---|---|---|---|
| 1 | cc 对象与自家对象的函数互调：整数、指针、浮点、小结构按值的双向调用逐目标具名对拍 | R20-4 | v0.0.20 的符号计划与链接阶段统一 |
| 2 | `-run` 转发：多源、变参调用点类型、结构按值；Windows GetProcAddress 另列平台证据 | R20-5 | 1 的对应 ABI 形状通过 |
| 3 | 动态库最小往返：`-shared`/`-fPIC` 与 dlopen/dlsym，按目标分别验收 | R20-9 | 1；未完成的平台明确拒绝 |
| 4 | Windows 宿主头/Win32/Winsock 与 COFF 文本；Mach-O 文本、Intel 语法、内联 asm 子集分别验收 | R20-7、R20-8 | 相应平台的参考与产品路线 |
| 4a | **统一 Unix 兼容 libc（主人 2026-10-02 建议，参考 cosmopolitan）**：按 [设计](../research/libc-unify-design.md) 推荐一，“转发层 + 头文件分层”——Windows 两个架构把 POSIX 转发到 Win32（HANDLE 上的 fd 表、UTF-8 路径、Win32 错误码到 errno），macOS 两个架构转发到 libSystem，Linux 照旧走系统调用；POSIX 头单独成一层，`<windows.h>` 与 macOS 框架不受影响（内部名用 `__ux_` 前缀，`-D__UX_NO_POSIX` 恢复严格原生）。步骤 0 先立头文件分层骨架；步骤 1 是 Windows fd 表与 open/read/write/close/lseek/stat/unlink，门禁为两个 Windows 架构上探针输出与 mingw-w64 构建逐字节相同。不做 Windows fork | 主人建议；设计 research/libc-unify-design.md（只是设计） | 先核实 Mach-O 写出器能否在正式二进制里导入 libSystem 符号，以及 Windows 虚拟机里是否有两个架构的 llvm-mingw；未过门禁的函数族维持按名拒绝 |
| 5 | Csmith 固定种子分片进入差分队列，列出过滤规则、超时和已知错例 | R20-10 | combo 门禁可复用 |
| 6 | libc 后续批次：sigaction、setjmp/longjmp、pwd.h、IPv6 文本、strftime 扩展；sqlite/lua 语料按依赖逐个入门禁 | R20-6 后半、R20-12 | setjmp 先于 lua，pwd.h 与容量边界先于 sqlite |
| 7 | 论文 A 投稿级同身份重测与平台矩阵，失败的主张降级 | R20-11 后半 | 冻结候选与版本身份 |
| 8 | 产品 Mach-O/COFF 对象：先复测符号计划统一后的成本，再决定是否列为本版可交付项 | R20-13 | v0.0.20 链接阶段验收；条件未满足则只交评估 |

| 9 | 产品侧拒绝补齐位置与结构化帧：B1 五类（#28 多单元 static、#35/#36 `#if` 表达式、#34 arm64 兜底、#24 嵌套引号 include）都带 file:line:col 和 UNCOVERED 记录；A2 续行之前 token 的 `__LINE__`（两侧） | 0.1.x 附录“正确性与诊断债”提前（2026-10-02） | R20-2 帧契约（0.0.20）；`diag` 的“5 known missing”降到 0 |
| 10 | D1 通用 BANK 调用计划：SysV MEMORY 类聚合、寄存器耗尽、HFA，与第 1 项共用调用约定事实；c-testsuite 00204 差异随之复核 | 0.1.x 附录 D1 提前（2026-10-02） | 与第 1 项同批设计，第 1 项先落整数/指针/浮点 |
| 11 | POSIX 余项：`posix_spawn`、~~`sys/un.h`~~（已提前随 0.0.20 交付，hosthdr unixsock 两平台通过）、DNS 最小解析（`getaddrinfo` 读 /etc/hosts 与 UDP 53）；Windows 侧映射归第 4 项 | 0.1.x 附录“POSIX L2”剩余部分 + dsh 清单 | 每项与 cc/gcc 对拍，hosthdr 探针 |
| 12 | 外部裁判登记由门禁检查（33 个网络裁判齐全）与决策代码行数账本（连续版本数据） | 0.1.0 中的工程型条目提前 | 只做登记和计数门禁，不做 T2 证明 |

执行时优先并行无交叠的 1、4、5；2/3 等 1，6 内部按前置条件推进。每个单元先有红例、再做参考与产品对拍；每个目标的未覆盖路径按名拒绝。范围超出版本容量时须更新此表的承诺和降级原因，不能用整项“完成”概括局部平台通过。
