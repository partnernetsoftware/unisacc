# unisacc v0.0.17 计划（草案，2026-10-01；政委补充 + 董秘草案，按依赖调整）

> 基线：v0.0.16。**主线：自带链接器**——unisacc 自己的 `.o` + 系统 cc 的 `.o` + `.a` 静态链接成六目标可执行文件。结项条件：本地 `tests/release.sh --com` 全绿且 origin `release-check` 绿。顺延规则同 [v0.0.16](v0.0.16.md)：同一项顺延两次必须降级或砍掉。

| 序 | 项 | 优先级 | 工作量 | 依赖 |
|---|---|---|---|---|
| 1 | R17-1 Mach-O 与 COFF 的 `-c` | P1 | 大 | 0.0.16 ELF `-c` 与设计文档 |
| 2 | R17-2 自带静态链接器 | P1（主线） | 大 | 1 |
| 3 | R17-3 `ar`/`ranlib`、`nm`/`objdump` 式查看 | P1 | 中 | 1（`ar` 是 2 读 `.a` 的前提） |
| 4 | R17-4 `-g` 第一步：DWARF 行号表 | P1 | 中 | 1 |
| 5 | R17-5 语料加 lua + 由语料决定的库面（原 R16-4） | P1 | 中 | 0.0.16 语料门禁 |
| 6 | R17-6 流程：E1 冷缓存预热自动化、E2 gate.sh 与 all.sh 合成一张清单 | P1 | 中 | 无 |
| 7 | R17-7 POSIX L2 头 + 狗粮启动器切换（原 R16-3） | P2 | 大 | 5 的库面 |

依赖说明：1→2→（`-L/-l` 生效）；3 的 `ar` 早于 2 的 `.a` 输入；7 最大且与主线无关，**是本版唯一允许顺延的项**（已顺延一次：原 R16-3；再顺延即降级到 0.1.x）。

## 条目

- **R17-1 Mach-O / COFF `-c`**：复用 0.0.16 ELF 写出器的结构（符号表、重定位），格式层分三份；验收：osx 两目标与 win 两目标各一例，与系统 ld64 / link.exe（或 lld）互链运行一致。
- **R17-2 自带静态链接器**：输入 unisacc 的 `.o`、系统 cc 的 `.o`、`.a`；输出六目标可执行文件；`-L/-l` 从“接受但无效”变为生效。验收：fb12 多单元夹具分别编译再链接，与一次性编译行为一致；与系统 cc 的 `.o` 互链；两侧（参考与产品）一致。
- **R17-3 `ar`/`nm`/`objdump` 式查看**：`unisacc.com ar|nm|objdump` 子命令，读写三种格式；验收：与系统工具对同一 `.o`/`.a` 的输出（符号名、类型、段）一致。
- **R17-4 `-g` 行号表**：只写 DWARF `.debug_line`（Mach-O 走 dSYM 或内嵌），lldb/gdb 能按源码行下断点；`addr2line` 能用。PDB 与变量信息在 0.0.18。验收：lnx 与 osx 各一例脚本化断点命中。
- **R17-5 lua 语料 + 库面**：lua 带动 setjmp/longjmp 与一批 string/stdlib/stdio/math 函数；实际补哪些由 0.0.16 语料失败原因排名决定——2026-10-01 首轮实测的顺序：① `setjmp.h`（lua 的第一个拒绝）② `unistd.h`（jsmn-dump、kilo）③ `termios.h` + `sys/ioctl.h`（kilo）④ `pwd.h` 与 4 MB 源缓冲上限（sqlite，需把 MAXSRC 提到 16 MB 或分段读入）；每个函数红例对拍 gcc。验收：lua 自带测试的一个子集与 gcc 编译版输出一致；语料“每版至少多过一个”。
- **R17-6 流程**：冷建网络挪进 release.sh 队列前的预热步（E1）；gate.sh 与 all.sh 从一张清单生成（E2），CI 不再暴露本地没跑的套件。
- **R17-7 POSIX L2 + 狗粮启动器**：unistd/fcntl/sys/stat/sys/wait/spawn；lnx/osx 走 .sys，win 映射 Win32；镜像尾部命名数据块替代 ZipOS（docs/dogfood-targets.md）。

**不做**：训练；汇编器与动态库（0.0.18）。
