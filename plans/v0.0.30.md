# v0.0.30 计划（0.0.29 已于 2026-10-06 公开，本计划转正；收官路线见 plans/roadmap-0.0.x.md）

来源：roadmap 0.0.30 行，0.0.29 顺延的项，以及主人 10-06 的三条指示：
1. 改进管道和思路；
2. Python 编译吃光 4 GiB 内存明显不对，要查清；
3. 种子层尽快改用 C 重写，自举相关的计划提前。

规则同前：
- 一项最多顺延两次；
- 版本号提交前 ledgercheck --final 结清；
- precheck 对本版号的 knownfail 判红；
- 不砍，只顺延到具名版本。
