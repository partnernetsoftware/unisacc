## 返工的原因(按代价排序)
1. **约束检查只测单个翻译单元**:A6 的 END_ 未按 TU 清空、局部 enum 数组被误当 VLA,都因验收例全是单 TU;固定 43 与 59 例均漏。→ 规则:约束类检查的验收例必须含多 TU/模块/嵌套作用域。
2. **私有绿、主树红**:peep-cases-gen、c99-whitespace、s9-p3-pins、coverage 非法状态各发生一次(新文件未被 git ls-files 扫到、钩子只扫暂存、元数据无校验)。→ 已补:cxtrunc 扫未跟踪、钩子加 metadata_valid 闸、toolsloc 按暂存树计、提交后必跑主树全量棘轮。
3. **共享主树半成品污染**:L0' 常量表迁移使 all-waves 编不过。→ 硬规则:验证中的改动只在私有克隆。
4. **身份记录与源码耦合**:版本关口(目标 0.0.47 未升)、bootstrap sidecar 字节差异、sourcepackage 硬 pin。→ 记入 0.0.48 M5:派生记录除摘要外核完整字节与来源提交。
5. **评审里可数的断言未复核**:cx/driver/sys 是软链非重复副本、APE 里模型包只有一份、m27/m22 是代码对象。→ 规则:评审结论排期前用一条命令复核。
6. **环境/路径类假失败**:材料脚本内嵌构造 ROOT 绝对路径(streams 材料)、旧参考不可重建(make ref)。→ 对照结论必须先排除材料断路;材料不得内嵌绝对 ROOT。
