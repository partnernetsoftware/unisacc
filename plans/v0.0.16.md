# unisacc v0.0.16 计划（草案，2026-09-30；原定 0.0.15 的功能项顺延至此，主人要求 0.0.15 先做整理）

> 基线：v0.0.14（tag 75ec4de）+ v0.0.15 的整理结果。0.0.15 的“剩余问题清单”产出后会补进本文件，并重排优先级。

## 承接项（来自 0.0.14 回执与各计划）
- **R16-0 R14-8 余项（P1）**：b_compound、b_pp2——全局初始化器里的复合字面量，产品先造 `__cl` 临时对象再拷贝、.bss 声明顺序不同；程序行为一致，镜像不同。验收：`exec/c/chain.knownfail` 清空，exec-chain 全等。
- **R16-1 R14-3b**：同一行续行拼接点之前 token 的 `__LINE__`（及诊断行号）多 1，两侧同错；拼接点列坐标要穿过去注释一遍。验收：新红例与 cc 同，C99 账本 6.10.8 回到 covered。
- **R16-2 C99 语言缺口**：复数类型（6.2.5、6.3.1.6-7、7.3、附录 G）、三字符组替换（5.2.1.1）；先决定做或明确不做（后者要在账本与 README 写理由）。
- **R16-3 狗粮启动器切换**（docs/dogfood-targets.md）：POSIX 最小面 L2（unistd/fcntl/sys/stat/sys/wait/spawn；lnx/osx 走 .sys，win 映射 Win32）、镜像尾部命名数据块替代 ZipOS、平台判定用目标宏；minicon 六格启动器用 unisacc 构建并过 six-cell-smoke。
- **R16-4 库面**：C99 账本里 lib 条款 unsupported 191 条中按使用频度挑一批（string/stdlib/stdio 余项、ctype/wchar）；每个函数红例对拍 gcc。
- **R16-5 CI 慢 runner 与冷缓存**：冷建网络挪进队列前的预热步（release.sh 自动做），不再靠人工预热；Intel runner 维持参考性。
- **R16-6 论文 A 的阶段独立公理写入正文**（research/paper-a-notes.md 待办，若 0.0.15 未完成）。
- 远期条目（tapebin 平台化、内存安全节点、包市场 + agent 友好）仍在 plans/v0.1.x.md，不在本版。

**不做**：训练；扩大神经化到 .S / back_encode；分支/工作树开发。
