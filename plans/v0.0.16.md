## 本版条目

- **R16-8 origin CI 转绿（P0）**：origin `release-check` 自 300e8c9 起一直红（ci plan 自检 FAIL：knownfail keys、bound.py 命令形状），0.0.15 结项时未看 origin 就判了绿，这是流程漏洞。先修自检，再把“origin 绿”写进结项条件与 RELEASE-PIPELINE §9。验收：`gh run list -w release-check` 最新 main 提交为 success。 **[v] 2026-10-01 127b6b1**：原因是 0a8d265 让 all.sh 经假 python3 调 `knownfail.py keys`，ciplancheck 把它数成派发任务；自检改为只数 bound.py 派发。release-check 对 127b6b1 success（run 见 gh）；结项条件已写进 RELEASE-PIPELINE §9。
- **R16-9 减法安全门禁（P0）**：0.0.15 两次事故——AGENTS.md↔CLAUDE.md 链接成环致规则清空（bc86247），归档了仍被 7 个 lib 检查导入的模块致 8 项红（30be224）。新门禁 `subtract-safety`：① `archive/` 下的每个文件在 `archive/` 之外无人引用（import、source、路径字面量）；② AGENTS.md 与 CLAUDE.md 解析后非空、不是链接环。验收：对两次事故各造一个反例，门禁都能抓到。 **[v] 2026-10-01 db59cd5**：`tests/subtractsafety.py`，门禁 `subtract-safety` + `subtract-safety-selftest`（自测重建两次事故并要求抓到）；首跑抓到 3 处指向已归档 plans/v0.0.14.md 的旧链接，已改。
- **R16-0 A1 复合字面量**（原文不变）：全局初始化器里的复合字面量，产品先造 `__cl` 临时对象再拷贝、.bss 声明顺序不同；验收 `exec/c/chain.knownfail` 清空。
- **R16-1 A2 续行 `__LINE__`**（原文不变）：拼接点之前 token 的 `__LINE__` 多 1，两侧同错；验收新红例与 cc 同，C99 账本 6.10.8 回到 covered。
- **R16-10 诊断位置**：B1 产品侧 9 类、B2 参考侧 3 类拒绝补 file:line:col；验收 `tests/diag.knownfail` 清空。
- **R16-11 依赖生成**：参考侧已有 `-M/-MM/-MD/-MMD/-MF/-MT/-MQ/-MP`（src/main.c），产品报 “option not migrated”（2026-10-01 实测）；迁到产品驱动，输出与 gcc 同格式。验收：对 fb12 夹具与 gcc 的依赖文件逐字比较。
- **R16-7 工具链第一步（收窄，政委 2026-10-01）**：本版只做 ① **设计文档** docs/toolchain.md（格式范围、重定位种类清单、与系统工具互操作矩阵、三版递进）；② **ELF `-c`**：写出可重定位 ELF `.o`（符号表、重定位），与**系统 ld / cc 的 `.o`** 互链成可运行程序，lnx/x86_64 与 lnx/arm64 各一例 + difftest 子集一致。今天 `-c` 写出的是 tape 文本、`-S` 也是 tape（实测），README 须如实写。Mach-O/COFF `-c` 与自带链接器在 0.0.17，汇编器在 0.0.18。
- **R16-12 真实程序语料门禁（起步）**：`tests/corpus/` 固定版本的真实程序，产品与 gcc 编译后行为对拍；本版先过 **kilo、base64、md5、wc、grep（小实现）** 中尽可能多的几项，并登记全语料（kilo、lua、sqlite、base64/md5/json/wc/grep）的当前失败原因。规则：**每版至少多过一个**；失败原因排名决定 R16-4 先补哪些库函数（如 lua 要 setjmp）。Csmith 差分与 GNU 扩展子集在 0.0.18。
- **R16-2 复数 / 三字符组**：本版只做决定；做就排进 0.0.17/18，不做就在账本与 README 写理由。
- **R16-13 工具链盘点表**：见 H 节，每版结项时更新状态列。
- **R16-14 发布前必跑清单**（写进 release/RELEASE-PIPELINE.md）：Windows `-run` 义务（UTM 开机后 crossnative）、六平台外部执行/自举证据（release-check 六 runner）——0.0.15 因不发布而未验证的两项，下一次发布前必须补跑。

**不做**：训练；扩大神经化到 .S / back_encode；分支/工作树开发。
