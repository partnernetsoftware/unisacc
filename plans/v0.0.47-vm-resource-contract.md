# UNIKERN1 执行器资源合同缺口清单

范围：0.0.47字节码切片种子的前置调查；不修改产品输入，不声称实现修复。当前产品链接`sys.kernel`（`src/executor.cx:2`），不能只审CX参考路径就代表实际汇编核。

| 资源/接口 | 已有合同与证据 | 缺口及最小验收方向 |
|---|---|---|
| 输入属性 | CX `cx/core/execute.cx:199-200` 对每输入字节分配一个64位属性；x86_64核 `exec/c/asm/run_x86_64.S:64-70` 同类分配 | 32MiB输入的属性名义额外约256MiB，尚未按实际模型需求稀疏/延迟化；应以同模型同输入证明输出/状态不变且峰值内存下降。不能仅凭初值全零删除表示、分配或失败合同；XATTR/SETOT生产可达性仍未证明 |
| 长度与乘加 | CX `inputn`是int，`execute.cx:188-200` 在分配前计算`inputn+1`；汇编核对应`:64-66` | `INT_MAX+1`的有符号边界未显式拒绝；C语义与机器回绕不能当等价。负值、INT_MAX、加一/乘8溢出应在访问前同类明确拒绝，不能靠calloc失败兜底 |
| OOM与调用者控制权 | `execute.cx:54-55,195-200`走`core_host_panic`；`src/host.cx:205-208`直接exit；汇编`run_x86_64.S:250-253`走panic；`exec/c/asm/README.md:255-256`及`exec/c/CORE.md:34-35`不承诺恢复清理 | 当前不是可恢复API失败；panic绕过正常释放路径。须先定资源错误码/输出所有权/清理合同，再做逐分配点失败注入；返回后活跃分配为零且调用进程可继续，不能把OOM冒充坏输入拒绝 |
| 输出与属性增长 | `cx/core/output.cx:9`及`exec/c/asm/buffer_x86_64.S:44-57`增长字节和64位属性；结果边界`execute.cx:241-244`只交接输出字节、释放属性，汇编`:175-184`对应 | 输出增长缺独立字节/属性预算；不能因最终不导出属性就认定中途语义无用。先证明动作读写/跨帧合同，再考虑表示优化；覆盖扩容前保留值、失败原状态与零写占槽 |
| 步数、墙钟与取消 | `execute.cx:212-217`、汇编`run_x86_64.S:107,159-164`按transition计步，status3/reason timeout；`src/runtime/runexec.cx:124`默认400000000000 | transition预算不等于动作工作量、内存预算或墙钟；暂无已证明的外部取消合同。需分别界定transition/action/分配字节预算及可中断点，宿主watchdog不等于VM可恢复取消 |
| 正常返回与所有权 | `execute.cx:240-252`成功只转移out字节，err字节交调用者，释放栈/帧/内存池/blob/intern/resource；模型及原输入借用，注释`:4-6,41-42` | 正常路径已有明确释放，不能描述为普遍泄漏；缺的是OOM等非局部退出后同等级保证。还须核宿主取资源borrowed/owned两类和失败半成品释放 |
| 稀疏内存、栈、帧、intern/blob | `execute.cx:16-26,43-49`分别维护容量；主循环没有统一资源预算对象 | 各容器容量上界、整数溢出、增长失败及两ISA一致性尚未完整证明。后续必须逐容器列边界，不把“无统一预算”误称每个容器都无检查 |
| 核加载生命周期与平台 | `cx/sys/kernel.cx:108,114-115,126-131`映射/调用核；`exec/c/asm/run_x86_64.S:6-8`的Windows构造路径有限制 | 内核映射进程生命周期与重复装载回收需单列；Windows对应具体构造路线的限制不等于整个产品Windows不可运行。arm64逐动作资源行为、加载来源/身份边界仍需专门验证 |

## 进入字节码试点前的决策门

1. 先确认资源错误可恢复、调用返回后的所有权，以及输入/输出属性表示合同；未经此门不把大状态编译逻辑直接搬进VM。
2. 测试矩阵至少包含空输入、长度边界、每类容器扩容、每个分配点失败、步数超限与取消；CX和两ISA核比较状态、reason、stdout/stderr及分配计数。现有`exec/c/asm/runcheck.c:12,53`的分配记账可复用，但本轮未执行这些测试。
3. 现有`CORE-INPUT-MEMORY-OOM`仍未修；`VM-BYTECODE-SLICE`完整实现/收益测量未启动。模型解码nrg上界、stack汇编容量保护、arm64全路径、XATTR/SETOT生产实际使用列为未证明，不能以本清单关闭。
