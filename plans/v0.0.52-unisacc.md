# unisacc 0.0.52 计划(占位):主题「模型层迭代开始」(cc 2026-11-10 起草;以 0.0.51 实测为前提,届时复核)

## 0. 前提(0.0.51 必须达成,否则本版顺延)
- 改一张事实表到可安装候选 <= 5 分钟(G2 增量链),每轮模型实验的构造成本为分钟级。
- s9 提交档单 step <= 300s,daily 档每夜自动跑;模型改动的回归验证不占 agent 注意力。
- 候选构造自含、无借用输入、无隐性前提;oracle 以 0.0.51 发布版重基线。
