# CX-W-7 宿主驱动 `-run` 设计草案（2026-10-31）

状态：提案，未修改 `cx/spec.md`，CX-W-7 未生效；不触包根 CX-W-6、模块身份或 pragma。`gcc_cx`/`clang_cx` 仍依赖 PATH 上的系统编译器，产物是普通 C，不授予检查或内存安全资格。当前仓库根的 .com 是指向 `out/cxcc-host/` Linux x86-64 二进制的 shell 启动器，其他机器不据此授证。

## 语法提案

`sh ./gcc_cx.com -run [编译选项] FILE.cx [编译选项] -- [程序参数...]`；clang 同形。`--` 前是宿主编译参数、恰好一个 `.cx` 主文件；`--` 后逐项原样传程序，允许空字符串、空格、引号、反斜杠、`-o`、`--` 等，不经 shell 重新解析。无 `--` 则无程序参数。程序的 `argv[0]` 是本次临时可执行文件路径，不承诺与源码名或 unisacc 相同。

`-run` 不向系统编译器透传；与 `-o`、`-c`、`-E`、`-S`、共享库等不产生可直接执行程序的模式冲突时具名拒绝。到底能接受哪些组合，需对齐现有 `cxcc` 参数识别；未知编译选项仍交宿主编译器，不能为了误判而默默吞选项。原有非 `-run` 模式与其参数解析保持不变，不把裸 `--` 意外重新解释为程序参数。以上只是一组候选合同，尚待实现方和审阅确认。

## 进程与产物

1. 调用既有 CX 模块展开与宿主编译路径；不得将源码交给系统编译器直接忽略 `use`，也不得调用 `unisacc.com` 作为后备。
2. 每次运行建立独立、权限受限、不可预测的临时目录，路径由宿主安全创建原语原子取得；编译目标是该目录内从未存在的可执行文件，不能复用固定路径、已有产物或测试结论。目录父路径、平台 API 和错误行为明确；进程并行时互不碰撞。避免先创建可预测文件、关闭后在共享目录重新打开的竞态。
3. 编译退出非零、无法启动、无法创建产物、无执行权限均不得启动程序；保留有意义的编译诊断及状态。成功后以参数数组启动目标，继承当前工作目录、标准输入/输出/错误和环境；不另经 shell，保留交互和重定向。
4. 正常退出传递程序退出码；信号退出和宿主启动/等待失败单列明示，不将这些故障伪报为编译错误或程序正常退出。Unix 和 Windows 的进程返回与信号模型不同，不能以 Linux 结果推断 Windows。是否原样重发信号还是映射为 `128+signal` 须与既有 `cxproc_run` 和上层调用合同对齐后冻结。
5. 对编译失败、启动失败、运行结束后的临时文件做尽力清理，保证不删除不属于当前调用的路径。不可捕获终止/断电不保证清理；Windows 可执行文件仍在使用时的删除语义须按实际 API 处理和测试。清理失败应可诊断，不能掩盖程序失败，也不能伪装成已清理。
6. 现有无 `use` 的快速路径与含 `use` 的模块路径都须覆盖；不得由一个路径的通过推断另一个路径。`-run` 的可执行产物不可被通常的对象缓存或不同调用共享。

## 验收矩阵

同一候选驱动源码分别由宿主 gcc、clang 构造，在真实 Linux 宿主用两者各运行：

| 场景 | 必须观察 |
|---|---|
| 无 use 与跨模块 use | 正确输出及程序退出码；含 use 必须实际调用模块函数 |
| 参数 | 空字符串、空格、引号、反斜杠、`--`、以 `-` 开头的值均与传入逐项一致 |
| 环境与 IO | 设定环境变量、cwd、stdin 并核对 stdout/stderr；不得从 shell 拼字串间接伪造 |
| 程序退出 | 0 与非零可区分；信号结果按冻结的平台合同验证 |
| 编译失败／无编译器／启动失败 | 给出相应失败；程序副作用未发生，不执行旧文件 |
| 参数冲突 | `-run` 与不兼容输出模式拒绝；原有 `-o` 行为不退化 |
| 并发与临时物 | 同时运行两个不同程序，输出不串且结束后各自清理；不触及预置的其他文件 |
| 状态边界 | 不调用 unisacc 的情况下通过宿主驱动构造与运行；候选、已安装、平台切片各自记账 |

macOS、Windows、ARM 需对应宿主实跑后单列证据；只能写出构件或缺可用系统时标未验证。Windows 路径、`.exe`、CreateProcess 命令行转义与文件占用需要独立覆盖。保持六格 APE 的发布要求不等于本地 shell 包装已是 APE。

永久测试只测试消费者可见行为和真实拒绝，不照抄进程调用转发或打印模板。测试输入在运行期间不可变，单次命令及子进程均有独立上限；新测试按仓库现有批次登记。成功的局部验收不自动修改 CX-W-7 生效状态、安装候选或授权完整平台发布。
