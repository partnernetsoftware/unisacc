## P 项验收条款（草案，设计非实现；改码待 /goal）

**P2 hostcheck（cdx 提，10-09）**
1. 由真实 gate 作业声明（含全部分片与 --com 项）生成 suite→宿主/目标/工具/头/语料需求清单；清单与门禁双向差集为 0，每项有 owner 与探针；未声明项显式 UNKNOWN，不按 grep 到 Darwin 自动豁免。
2. 工具做最小实探：csmith 按正式 OPTS 生成固定一例并用声明 CC 与同一头编译；cc/clang 所需汇编/链接特性、libffi 与头路径分别测；记录版本、实体摘要、头摘要与宿主，不把 secret、原始 env 或绝对临时路径写进仓。
3. 负例：缺 csmith、仅有可执行而缺头、错误 CC 风味或不支持 -arch、错误 ISA、缺语料、显式路径工具不可运行——均在候选构造前报 MISSING/UNSUPPORTED/UNKNOWN；工具存在不等于 suite PASS。
4. 时长预测只读上一版同 suite/身份/宿主基线，缺基线记 UNKNOWN；wall、CPU、RSS 分列，不统一乘系数；PREDICT_TIMEOUT 只报告给 H1，不改 limit/window，不把 FAILED 变 PASS；节省只能下轮实测，不把估算写成完成。
5. 环境在正式执行前固定；预检后若换 CC/头/csmith/语料/候选/seed/关键 env，相关预检与 suite 结果失效（完整 fingerprint，不只按 HEAD+候选）；负例逐一改单个外部输入，旧结果须拒复用；候选/seed 尚不存在时可检宿主，但不得声明产品身份已过。
6. 探针与子进程沿用 ≤60 s、单窗 55 s 清理规则；无空检查成功；清单覆盖、就绪、实际验收、裁定接受分列；前检失败保留首错，不能安装后删除原失败。

**P3 活锁、共同 deadline 与中断（cdx2 提）**
1. 同机单调时钟，从父层起点扣前检/fingerprint/交接/收尾预算；suite 获准上限 ≤ 原上限与父剩余预算；不足即显式 BUDGET_UNSCHEDULABLE，不缩短运行后算产品失败。
2. deadline/attempt 不进 suite 环境与语义指纹；只改截止时间的下一窗可复用合法结果；工具/env/provider/seed/未跟踪输入真实变化照旧失效。
3. 启动前原子写 inflight；父杀或缺终态记 INTERRUPTED 及杀层，suite_rc 为 null，不伪造 142/PASS、不删失败；退出确认子进程回收，既有完成项保留。
4. 首次完整窗外杀且零进展即停诊断；连续三窗无新增合法完成为最迟停止线；driver 遇无进展不得按 75/142 盲续；合法预热/分片持久推进不误停。
5. 负例：慢前检挤占、父杀于 job 中/写账前、残留 inflight 重启、动态 deadline 变化、真实工具变化、三窗同四项零进展、预热持久推进；判据无活锁/无孤儿/无假 rc 或 PASS、复用准确、既有上限不变；之后仅一次授权正常窗口验证，不另起全量第二 queue。

**P6 阶段墙钟（cdx2 提）**
1. 十阶段 code/matrix/freeze/candidate/fixedpoint/accept17/seal/queue/draft/public；event_id/parent_id/attempt/phase/subphase，begin/end/wait 唯一配对；字段白名单，原始 argv/env/cwd/凭据不入。
2. wall 用同机同 boot 单调钟，UTC 供跨机排序，跨机/重启不相减；wall、user/sys CPU、RSS 分列，未测为 null 不记 0；RSS 不冒充并发树峰值。
3. rc、execution_status、acceptance_status、coverage、authorization_ref 分列；rc0≠阶段 PASS，授权放行≠全 suite PASS；缺 end/产物/覆盖保持 INCOMPLETE/UNVERIFIED。
4. 汇总器出 phase 总 wall、命令区间并集、等待/重试区间、缺测与身份证据；重叠不重复相加；不以提交跨度冒充阶段时长。
5. 负例：孤儿 end、重复 id、缺 end、多 attempt、重叠命令、跨 boot、失败后成功、非法/敏感字段、RSS 缺测、rc0 但验收失败；手算表与解析一致。原始记录仓外，脱敏汇总审阅后才入 research；首个完整绿跑作成功基线，不重跑 0.0.37 补表。

**P7 流程与套件同步（cdx2 + cdx 提）**
1. P3/P6 接口与套件/依赖声明同切口；依赖/检查器修改按现 contract 身份重验，不藏作调度改动。
2. 执行宿主与输出目标分开：Linux 可做 Mach-O/PE 交叉构造与字节对拍，不能因 target=osx/win 整项 UNVERIFIED；只有实际执行不满足的子项记 UNVERIFIED（列 required/observed host、target、缺失条件）并保留覆盖义务；不把 macself 换成 ELF、不删跨目标项、未执行不计 PASS。
3. 结果四类独立：PASS / FAILED / UNVERIFIED，裁定另记 ACCEPTED_BY_RULING（具名范围与引用）；宿主 cc 报错、真实输出不符、ASan/LSan 报告先保留 FAILED，不凭 Linux 或 stderr 关键词归为 host-only；关闭 sanitizer、放宽 -Werror、改 errno 预期不默认算适配。
4. nativecheck 负例：Linux/x86_64 选 lnx/x86_64 + run.elf + bundle lnx/x86_64，Darwin/arm64 仍 osx/arm64 + run.macho；未知宿主/ISA 明确不支持；网络与 compiler 构造 runtime 逐字节相同的原判据不变；e6910112 仅语法绿、独占 55 s 冷准备 rc142，不算功能完成。
5. 工具安装或头路径适配后只在原覆盖与完整身份规则内定向重验；csmithdiff 40 片 seed 范围/OPTS/knownwrong 不改，0.0.37 独立 state 的 36 PASS/4 timeout 回执保留。
6. 套件自证负例：不适用宿主、适用宿主成功/真实错误、工具缺位、合法交叉目标、同 deadline 不同窗、真实依赖变化、外杀时缺 end；选择集合与既有覆盖不减少，预检缺项与实际消费依赖一一对应。
