# unisacc v0.0.22 计划（草案）


## 政委指示（2026-10-02，0.0.21 发版后开工）：论文 A / A2 同行调研

- 范围：论文 A（工程技术报告路线）与新开的论文 A2（科学学术路线：可证伪的研究问题 + 对照实验）都做同行调研。
- 检索词：基于神经网络的编译器、neural compiler、LLM-based compiler、learned compilation 等；实际下载同行论文与工程报告，PDF 只放本地（不进公开仓库），仓库只放逐篇阅读笔记与书目。
- 正文：多维度比较表（方法、模型在编译流程中的位置、目标平台、正确性保证与验证方式、评测基准与数据、可复现性、开源与许可等），每个结论可追溯到具体文献。
- 附录：严谨书目（作者、标题、年份、发表处、arXiv 号或 DOI、URL），不许编造引用；每条都要本地有 PDF 或可访问页面为证。
- 另出一份“启发与后续改良方向”清单：同行做得更好或我们没想到的点，逐条排进后续版本计划。
- 目的：支撑 arXiv 发布与项目宣传。
