## 一、范围与设计裁定

1. **只做 `L` 与 `R` 标号按函数名限定**:
   - 函数入口(`exec/parse2/control-result.tsv:1413` `function8-plain FN.go` 与 `:1450` `function8-warnings FN.go`)将 `lab` 清零后递增(`["LDI","lab",1],["COPYW","rl","lab"]`),使每个函数内部 `rl=1`、后续分支标号从 `2` 起独立计数,不再跨函数累加。
   - 生成的编译器局部标号由 `__unisacc_L<n>` / `__unisacc_R<n>` 改为带当前函数名 `[fns, fne)` 的 `__unisacc_L<fn>.<n>` / `__unisacc_R<fn>.<n>`(多单元下经 `tapelink` 前缀为 `__u<N>___unisacc_L<fn>.<n>` / `R<fn>.<n>`),仿 `u_{@name}.` 先例。
   - 文件域兜底:函数外(若顶层 `sizeof` 或复合字面量触发 `lab` 递增)在 `fns == fne` 时保持无函数名点号或以空名安全分隔。
2. **新增独立单调函数序号寄存器 `fn_seq` 给 `gotolabels` 键用**:
   - 原因:当 `lab` 改为每函数重置为 `1` 后,每函数的返回标号寄存器 `rl` 恒为 `1`;若 `exec/parse2/gotolabels-result.tsv:6,8` 仍用 `unit_epoch<<32 + rl + 1` 作为函数归属键,则同一编译单元内所有函数的 `glc_fn` 全相等——不仅同名标号跨函数覆写同一键,且**前一个函数定义了标号 `L`、后一个函数未定义 `L` 却写 `goto L;` 时会被误判为合法**(见最小先红负控 `L3_NEG_CROSS_FN_GOTO`)。
   - 做法:在 `startup-actions.tsv:2` 与 `gen2-manifest.tsv:107` 初始化 `["LDI","fn_seq",0]`,在 `FN.go`(`:1413`、`:1450`)执行 `["ALUI","add","fn_seq","fn_seq",1]`,并在 `gotolabels-result.tsv:6,8` 将 `rl` 替换为 `fn_seq`。
3. **`cx/compiler/tapelink.cx:435-444` `tl_loc` 同步适配**:
   - `tl_loc` 是 `tl_dce` 判定编译器局部标号的唯一解析器;扩展为识别 `[__u<digits>_]__unisacc_[LR][<ident>.]<digits>`,同时兼容新旧两种形态,确保 `tl_dce` 死代码删除不退化。
4. **明确不进本版(留二期与 `0.0.103` U7)**:
   - 串池 `S<sk>` 与静态局部 `ls<n>` / 复合字面量 `__cl<n>` 函数局部化留标号二期;
   - 本版为使能项,自身不省毫秒,旨在使函数内 `e3`/`e4` 标号输出与前序函数分支增删解耦。
