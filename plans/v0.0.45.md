# 0.0.45 计划（待启动）

<a id="registered-requirements"></a>
## 已登记需求（主人2026-10-24）

继续改良现有流＋网范式的模块，使其成为外部可以调用的工具能力；让不同用途的`.com`程序动态共用模块与权重，支持更丰富的测试、诊断及应用功能。当前仅登记需求，尚未完成本版设计或实现，不构成0.0.43发布前置。

| 编号 | 需求 | 设计与验收方向 |
|---|---|---|
| C45-FLOWNET-01 | 改良流＋网模块的可复用边界 | 沿现有Stream／Net合同整理可独立调用的能力、依赖及组合方式；保留流与网的语义区别，调用不要求复制整套编译器或另写一份实现。 |
| C45-CALL-01 | 形成外部工具调用接口 | 明确外部`.com`调用模块的入口、输入输出、资源与内存责任、诊断、拒绝及版本兼容合同；支持按需组合模块完成具体功能。API形式、承载格式和装载方式后续设计，不在登记阶段预定实现。 |
| C45-SHARE-01 | 多种`.com`程序动态共用模块和权重 | 明确模块／权重包的发现、加载、复用、身份和配对校验，避免每个工具各自复制逻辑与权重。分别计量公共模块／权重及每个调用程序的大小、加载成本和运行内存；不将多份拷贝或转调旧脚本称为动态共享。 |
| C45-TOOLS-01 | 用实际工具证明能力可外用 | 至少用两个不同用途的`.com`程序复用同一组模块及权重，展示具体测试或诊断功能；逐项比较现有入口与外部调用的结果、拒绝和边界，覆盖缺失／不兼容模块、权重身份不匹配及资源释放。保留独立参考，不以同一实现对自身比较冒充对拍。 |

与0.0.44的关系：0.0.44改进`.cx`语言／工具链的模块化及内存安全；本版进一步把编译器的流与网能力作为共享工具模块开放。后续排程基于已实现事实细化，思维树与记忆宫殿随状态变化原位更新。
