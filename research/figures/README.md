## IEEE / 投稿排版约定（本仓自用检查单）

- **矢量优先**：投稿用 SVG→PDF/EPS；位图备用 ≥300 dpi、线稿黑白。
- **图注在图下方**，正文用 “Fig. 1”；中文稿可用 “图 1”，投稿英译时统一 Fig.
- **无装饰**：无渐变、阴影、彩色依赖；打印灰度可辨。
- **字号**：图内标注约 8–10 pt（本 SVG 以 Helvetica/Arial 计）；缩到单栏后仍可读。
- **图内不放证明细节**：∀k 枚举等写进 caption / 正文，避免图面过载（本图 Notes 可在终稿改入 caption-only）。
- LaTeX 例：`\includegraphics[width=\columnwidth]{fig1-deterministic-intnet}`
