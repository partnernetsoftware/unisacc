# K2b 的 C 执行夹具修复

实际跑过；F3 尚未全绿，本记录只结 K2b 这一刀。

迁移后的 volatile-comma 使用 cxbin 与 C Tape VM。旧夹具只复制跟踪文件，漏掉被忽略的根产品，原红为 `cxbin: no compiler`。通用 `tests/withproduct.sh` 在私有导出中显式带入并跟踪产品对，先以 ident 校验来源；清除继承的 Git 定位变量，私有 Git 操作不会使用外部索引。导出保留为 scratch 的运行证据。原 K2b 检查器的逻辑与断言不增加、不删除。

补齐产品后，原 N10 修改已脱离运行路径的旧 VM 文件，实测断言报红。只替换三处夹具数据常量：遗漏 include 目录声明、向 cx.h 注入编译错误。cxbin 的键补入顶层前奏头名称和内容，头变更触发真实重编译；此处没有宣称完整模块/传递依赖闭包缓存。

在索引导出、空家目录和临时目录的隔离中，现有清单工具独立有界准备后，完整原 K2b 测试 rc0，原成功长句完整输出。新的 narrow 与 whole-tree 真实执行结果均 rc0，stdout 摘要一致；随后 N10 确认缺失依赖未失效时真实执行变红，结果被撤销并保留 void 记录。未放宽超时、未添加豁免，也未把先前失败改记通过。
