## 点采样（python `VM(tape, max_steps=N).run()` 对拍）
- 7 个程序，CODE / STEPS / OUT 逐字节相等：
  - `arith`：7、5 上的加乘减，退出码 53（步数 6）。
  - `divmod`：-7 上的有符号 div/mod（-3、-1）、算术右移（-2）、逻辑右移（4611686018427387902），四次 print，退出码 -3 & 0xFF = 253；输出 `-3-1-24611686018427387902`（python 与 C 相同）。
  - `loop`：1..100 求和（5050，经 store/load 与 print）后 print 的门限 clobber 使 r0=0，call/ret 加 9，退出码 9（步数 512）。
  - `spin`：无限循环，步数上限 50，停机 124（步数 51）。
  - `fault`：load64 于 MEM_SIZE，停机 139（步数 2）；C 与 python 均向 stderr 打印 fault 行。
  - `divzero`：无符号除零，停机 136（步数 3）。
  - `narrow`：.st 写 0xFF 一字节，.ld 一字节符号扩展为 -1，print "-1"，随后 r1 被门限 clobber，退出码 0xA1 = 161（步数 6）。
- C 双跑确定性（7 点）。

## 负例（3 个，两侧同拒且 stdout 空）
- `unknown-op`（`frob`）：python 在 emit 处断言（AssertionError）；C 在建树时拒绝。
- `bad-register`（`r9`）：python 在该指令执行时 KeyError；C 在执行时拒绝（运行时才报）。
- `unknown-label`（`nowhere`）：python 在跳转执行时 KeyError；C 同样在执行时拒绝。
