QUESTION 1: hash-cons a type descriptor in one action-table row with SBINTERN
VERDICT: GO for the mechanism (one branch-free row per derivation step; tape byte-unchanged on 650/650).
         PARTIAL for "TDESC by projecting the old registers": the projection is lossy in exactly the expected places.
======================================================================
Mechanism (只读推断 from exec/c/core.c:330 and seed/tbl.c, then 实际跑过):
  - SBINTERN interns the scratch buffer in the SAME table as identifiers (core_intern, ids sequential ++n).  So equal byte strings
    give equal ids, i.e. hash-consing for free and without a branch.  To keep type strings disjoint from identifiers the
    interned key starts with byte 0x01 (no C token contains it).
  - There is no opcode that writes a register's value into the scratch buffer (SBOUT takes an immediate only).  The operand n
    (array length, base kind) gets there through the tape buffer: OLEN m; OUTW n; ALUI sar..8; OUTW (x4); OCUT blob m; SBBLOB blob.
    OCUT truncates the tape back to m, so nothing remains in the output.  Safe only while osel==0: E3 sets OSEL 1 only inside
    diagnostic emission (2 places, both restore 0), never at a declaration commit.
  - Descriptor encoding: cells of 5 bytes, read from the name outward: op byte ('b' base, 'P' pointer, 'A' array) + 32-bit LE
    operand; a cons prepends one cell to the child's body.  The cons row (one action sequence, no CMP, r-neutral, 25 actions):
      COPYW kid,ty; LDX cb,ty,TYBLOB; OLEN m; OUTW n; (ALUI sar t,..,8; OUTW t) x3; OCUT nb,m;
      SBCLR; SBOUT op; SBBLOB nb; SBBLOB cb; SBSAVE body; SBCLR; SBOUT 1; SBBLOB body; SBINTERN ty;
      STX ty,TYBLOB,body; LDI t,op; STX ty,TYOP,t; STX ty,TYN,n; STX ty,TYKID,kid
  - TY zone: memory banks TYBLOB/TYOP/TYN/TYKID at 2.000e15..2.003e15 (+ty), STY[v] at 2.004e15 (largest existing E3 base:
    1.128e15).  Registers: tyx, tyx_* only (10 new names; checked absent before).

Prototype (S/r3a-prototype.diff): local declarations only.  DC.p (the commit after DIMSAVE, declaration-result.tsv body) now goes
to TY.base instead of RET.  Rows: TY.base cons 'b'(tb); TY.p.test loops td times consing 'P'; if dar, TY.k.test loops
k = drk-1 .. 0 consing 'A'(TDIM[k]); TY.done: STX v,STY,tyx and re-establishes r=1 (the value both incoming paths leave)
before RET.  Constructed by seed-gen (["constant","TDIM"] is not bound in this section: unknown constant binding; the
numeric 29000000 was used).

Caveats found (实际跑过 unless marked):
  - Shared intern table: every type string takes an id from the identifier sequence, so identifiers first seen after the first
    local declaration get different ids than before (blob ids likewise).  650/650 shows no id leaks into the tape on this
    corpus; that is an empirical result, not a proof (只读推断: no OFILL/OUTW of an intern id was found, not exhaustively audited).
  - STY[v] is keyed by the symbol id: an inner declaration that shadows an outer one overwrites STY[v] and scope unwind
    (scope-actions.tsv restore, UNDO_n frames) does not restore it (只读推断).  R3 S1 must add STY to the scope save/restore frame
    (and declare it to statecheck), or key it by declaration rather than by name.
  - Each cons allocates two blobs even when the type already exists (memory only).  Avoidable with a branch, or with the
    branch-free alternative below.
  - Alternative without SBINTERN (只读推断, not built): a pure-ALU memo (key = child<<34 | n<<2 | op in A64; id = MEMO[key];
    isnew = (id-1) shr 63; id += isnew*(cnt+1); cnt += isnew; STX MEMO[key]) is also one branch-free row, uses a private id
    counter (no identifier-id shift, no blobs) but needs bounds on n and child ids.

QUESTION 2: does the `JUMP fpback` shadow rescan write any scope or symbol register?
VERDICT: NO-GO for the claim in general (statically reachable AND demonstrated: it binds scope entries and tags; one live
         not-covered reject results).  PARTIAL: on initializers without `sizeof` in a designator it writes none.
======================================================================
What the path is (只读推断, exec/parse2/control-result.tsv:329-343): FPDECL with an open `[]` and `=`: $dimension_state3 does
  COPYW fpback,tpos; vpush ips,ipe; INITCOUNT scans the initializer (counting elements, designators via CE), then
  $dimension_state6: vpop ips,ipe; COPYW fpn,dm_n; JUMP fpback (rewind) and the declarator/initializer are parsed again.
statecheck.cx has no per-path mode (its --regs is whole-network: "1407 registers in used sequences ..."), so the path proof uses
S/tools/seqw.c on the constructed delta plus the instrumented executor.

Dynamic (实际跑过; product == cc on all accepted probes):
  fpback1.c `int (*fps[])(int) = { f, g, f };`  window 171 steps, 24 registers written:
    dm_add dm_d dm_max dm_n dm_need dm_par dm_per dm_used fpback fpn ipe ips ixn pe pf_before pf_before2 pf_prev_e pf_prev_ord
    pf_prev_s pf_previous ps tk tpos vsp;  memory: only the value stack (7000000+vsp) for ips/ipe.   -> no scope/symbol write
  fpback2.c designators `[K] = f, [0] = f` (enum constant):  30 registers, adds ce_id ce_ok cv nd nv nx + intern-table lookup;
    memory: only the value stack.   -> no scope/symbol write
  fpback3.c `{ [sizeof(enum E { EA = 1, EB })] = f, f }`:  writes usp, v, tagusp, tg, en_*, rg_scope, vr_scope; STX into the
    scope undo stack UNDO_0..43 (3000000..3000043 + usp), symbol banks keyed by v (LOC/PTR/BASE/... 8000000, 36000000,
    35000000, 7696581394432, 57174604644352, 716881581309952, 12094627905536), tag banks (tagusp 1342177280..83, tg 1275068416).
    Consequence: the rescan re-declares E -> E3 rejects "not covered: enum tag redefinition" (product -S and chain rc 1), gcc 12
    accepts (exit 9).  A not-covered reject, not silent wrong code.
  fpback4.c `{ [sizeof(struct S { int a; char b; })] = f }`: writes tagusp, tg, sid and struct banks; accepted twice-defined,
    result equals cc (12).
  fpback5.c `{ [sizeof(f(3))] = f }`: writes v (saved/restored around the sizeof), late-binding site registers (lv_*, lc_site),
    emits and cuts tape (OUT/OUTW/SPAN2 + OCUT); result equals cc (7).
Static (实际跑过): `seqw pdregion w/e3.json fpback` (context-sensitive: 15652 (entry,state) pairs, 3793 call sites, 514 rescan
  edges reached, 0 escapes before the rescan): 6378 sequences, 1190 registers written, 583 distinct STX forms.  Scope/symbol
  registers among them: cur dar decl_register dsz fid fns infunc max sid sv tagmark tagscope tagusp tg usp v.
  Shortest chains (procedure level) printed by `seqw pdregion ... usp|tagusp|v`:
    INITCOUNT -> CE -> CE1..CE10 -> CE.atom (CE.sizeof.t/in/expr) -> SZ.p -> UNARY -> U.deref.body -> ... -> EXPR -> ADR -> CALL
      -> TSPEC -> ENUM -> BIND (usp)            [and ... ENUM -> TAG.SYNC -> EN.NEW -> TAG.bind (tagusp)]
    INITCOUNT -> CE -> ... -> SZ.p -> UNARY -> U.deref.body (LOOKUP: INTERN v)
  The direct route `sizeof(type)` (CE.sizeof.ty -> TSPEC) is the one fpback3/4 take.
Conclusion: the existing rescan re-executes whatever the scanned text does; any rescan that goes back through CE / TSPEC / EXPR
  repeats their bindings.  A TDESC shadow DECL (R4) therefore must NOT be a rewind-and-reparse through the shared subroutines.
  Safe designs: (a) cons at each declarator event in the primary pass (one cons row per '*', '[N]', '(params)'; Q1 shows the
  row is cheap, branch-free and output-neutral), so there is no rescan at all; or (b) a rescan whose constant operands are read
  from what the primary pass stored (TDIM/nv), never re-evaluated.  The fpback3 reject is a candidate probe for
  tests/c/candidates (not filed: no repo edits).

Plan B sketch (asked for the NO-GO case; applies to Q2 only -- Q1 is GO, so plan B is the differential oracle, not a replacement)
======================================================================
  - Outside the repo, a declarator stream (the E2 cell executor of research/c43-cx-paradigm-experiments.md, decl.tbl + tcheck.tbl,
    include-free .cx) reads the E1 typed token stream (or the source declarator text) and emits, per declaration, NAME<TAB>TDESC
    in the same cell encoding (b/P/A<n>/F(sig), name outward).  Constant dimensions come from the E1 stream as literal values;
    anything else (sizeof, enum constants, typedef names) is a named NOT-COVERED in the stream, never re-evaluated -- so the
    stream never binds anything.
  - E3 (with the R3 S1 rows) prints its interned TDESC per declaration only under e3/tdesc-trace; a .cx comparator joins the
    two by declaration order and reports EQUAL / LOSSY(projected != stream) / NOT-COVERED; the LOSSY set must equal the known
    lossy shapes ((*p)[N] before the row-shape projection, every function pointer before F(sig)).
  - Gate: tdescprobe domain (106 probes + 78 refusals) and the 650-file corpus, sharded <= 58 s.
