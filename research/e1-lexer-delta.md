# E1：词法层整体作为一台有限 δ（设计 + 可行性测量）

> 状态：设计稿 + 一次测量（2026-09-26）。对应 prd.md S-17 的 E1；机器定义用
> [`delta-framework.md`](delta-framework.md) §2，信任边界取 §3 的**选项 A**。
> 只回答词法层的规模，不外推到其它层。
> 产物：`exec/lex/gen.py`（生成 δ）、`exec/lex/sim.py`（只用通用原语执行 δ）、
> `exec/lex/compare.py` / `run.sh`（对照参考）、`exec/lex/mkpre.sh`（给参考二进制
> 加两个测量钩子，不改 `src/`）、`exec/lex/probes/`（边界探针）。

## 1. 参考是什么

参考是 `src/front_pp.c` 的 `lex()`，经 `-dump-tokens` 输出（`src/main.c`）：
每个记号一行，记号名取自 `TOKV`；种类 2/3/4（`id`/`num`/`str`）后跟 `=` 与源文本；
末行 `N tokens`。`-dump-tokens` 路径是 `splice → decomment → preprocess →
expandsrc → lex`，所以**词法器的输入是展开后的缓冲区**，不是源文件。E1 的 `x`
就是这个缓冲区；前面四步属于 E2。

参考 `lex()` 本身依赖的东西，逐项归属：

| 依赖 | 在参考里 | E1 中的归属 |
|---|---|---|
| 行拼接（`\` 换行） | `splice()` 在词法前完成 | E2；词法器看不到 |
| 注释 | `decomment()` 已删；`lex()` 仍保留 `cmt`/`linecmt` 两个动作 | δ 照样实现（在已测输入上是死路径） |
| 宏、`#include`、`\u` UCN 改写 | 预处理与展开；实测预处理把 `é` 改成 UTF-8 字节（于是词法器以 `unexpected character` 拒绝），`\U` 不改 | E2 |
| 首字节动作（这个字节开启什么，看下一个字节） | `inf(S_LEX, charclass(c), charclass(peek))` —— 模型/表 | 由 `weights/gold/lex.tsv` 展开进 δ 的 `DISPATCH`/`PEEK` 行 |
| 关键字、`type` 词、标点 | `TOKV`、`TYPEV`（由 `unisa/gold.py TOKS`、`unisa/front/lex.py TYPEKW` 生成） | 展开成 δ 的状态（§4、§5） |
| typedef 名 | 词法器**不**判定，一律发 `id` | E3（作用域/类型层） |
| 诊断的 `file:line:col` 与回显行 | `err_at` 用 `prelines`、`ireg_*`（头文件拼入区）、`spl_at`（拼接）、`nautoinc` 把缓冲区位置映射回文件 | **E2 拥有这张位置映射**；词法层只给出 `reject(k)` 与位置 `i` |
| `MAXTOK` 上限（`too many tokens`） | 资源上限 | 不建模（执行器资源，另报） |
| `tgt = "lnx/x86_64"` | 只影响预处理的预定义宏 | E2 |

## 2. 观测与 δ 能看见什么

`obs = (q, r, b, t)`：`b ∈ {0..255, EOF}`，`t ∈ Γ ∪ {⊥}`，`Γ = {P, D0..D9}`，
`R = {0..19}`。实现上**每个状态只读观测的一个分量**（`b`、`t` 或 `r`），并对该分量
全定义；这不是通配符，只是每一行的另外两个分量不影响结果。按 §2.2 的字面积
`|Q|·|R|·257·|Γ∪⊥|` 计是 20,662,800 格；实际表只有 85,123 格（§7）。

δ 自己区分字节，不靠执行器分类。`gen.py` 把 δ 的列按“所有读 `b` 的状态都不区分”
合并，得到 **δ 实际诱导出的 68 个字节类**（EOF 单独一类；162 个字节——控制字符、
`#@$\``、全部 ≥128 字节等——同一类，都走 `unexpected character`）。这比参考的
12 个 `charclass` 细，因为关键字 trie 要逐字母区分。

δ 看不见的东西，以及执行器如何只用通用原语处理：

| 看不见的 | 处理 |
|---|---|
| 记号的拼写（无界） | 不搬进 δ。`MARK S` 记下起点，结束时 `SPAN S` 把 `x[W[S]..i)` 追加到输出。 |
| 往回看/回退 | `MARK E` + `JUMP E`。只在四处需要：`0x1.5`（无 `p` 时退回 `.`）、`1e+x`（退回 `e`）、`..`（退回到第一个 `.` 之后）、字符串结束后的相邻字面量探测（退回右引号之后）。 |
| 括号深度（`__attribute__((...))` 的整段跳过） | 栈：`(` 压 `P`，`)` 弹；`ATTCHK` 读 `t` 判断是否回到 `⊥`；EOF 时 `ATTDRAIN` 清栈。 |
| 记号计数与末行 `N tokens` | `INC NT`；打印时 `DIVMOD10` 把余数与“商是否为 0”放进结果码 `r`，δ 把数字压栈再逐个弹出输出——十进制格式化也在 δ 里。 |

## 3. 执行器原语（选项 A，全部与 C 无关）

```
ADV                i += 1
MARK s / JUMP s    W[s] := i / i := W[s]          s ∈ {S, E, B, NT, T}
COPYW d s          W[d] := W[s]
INC s              W[s] := W[s] + 1  (mod 2^32)
DIVMOD10 s         W[s] := W[s] div 10;  r := W[s] mod 10 + 10·[商 = 0]   （无符号 32 位）
OUT b              追加常量字节
SPAN s / SPAN2 s e 追加 x[W[s]..i) / x[W[s]..W[e])
PUSH g / POP       栈
ACCEPT / REJECT k  k ∈ {unexpected character, stray char, unreachable}
```

`x[i]` 在 `i ≥ |x|` 时读作 EOF。一步 = 读观测、查 δ、置 `q`、依序执行动作。
动作序列是有限的常量序列，存在一个池里，表项只引用池下标。

## 4. 控制状态

共 **335** 个状态（331 个读 `b`，3 个读 `t`，1 个读 `r`）：

| 组 | 状态数 | 作用 |
|---|---|---|
| `DISPATCH` | 1 | 记号起点。`lex.tsv` 中对 peek 取值恒定的类直接执行该动作的首步；只有 `slash`、`dot` 两类的行依赖 peek（由表推出，不是手选） |
| `PEEK:slash`、`PEEK:dot`、`H:*` | 2 + 4 | 前进一字节看 peek，按 `lex.tsv` 选动作，`JUMP S` 回到起点交给处理器 `H:op/cmt/linecmt/num` |
| 标识符 trie `ID:*` + `ID*` | 236 | 见 §5 |
| UCN `UCN`、`UCNH4.k`、`UCNH8.k` | 13 | 标识符中的 `\uXXXX`/`\UXXXXXXXX`；畸形时 `JUMP B` 后拒绝，位置与参考相同（参考把名字截在 `\`，再以 `other` 拒绝） |
| `SKW:*`、`ATT`、`ATTCHK`、`ATTDRAIN` | 6 | `__attribute__`/`__asm__`/`asm` 后跳空白；遇 `(` 整段跳过，否则按普通 `id` 发出（`SPAN2 S E`） |
| 数 | 14 | `NZ DEC DFRAC DEXP0.i/f DEXPS.* EXPD HEX HFRAC HEXP0 HEXP1 SUFF SUFI`：十进制/十六进制、小数、指数、十六进制浮点、`fFlL` 一个或 `uUlL` 任意串 |
| 字符串 | 5 | `STR`、`STRWS`（右引号后跳空白）、`STRP1`、`STRPu`、`STRPu8`（下一个字面量的前缀）；相邻字面量并成一个记号，文本含中间空白，与参考相同 |
| 字符常量 | 1 | `CH`；`L'x'`/`u'x'`/`U'x'`/`u8'x'` 丢前缀，记号从引号起，种类 `num` |
| 注释 | 3 | `LC`、`BC`、`BCS` |
| 标点 trie `OP:*` | 47 | 最长匹配；状态 = trie 结点 + 最近一次接受的种类（只有 `..` 需要它） |
| 计数行 | 3 | `CNT0`、`CNT1`（读 `r`）、`CNTP`（读 `t`） |

## 5. 关键字：δ 上的 trie

关键字识别**由 δ 完成**，不用字典原语：工作存储初始为空（§2.1），关键字集合
不能预先放进 `W`，放进去就成了执行器携带的语言数据。trie 的词集合：

- `TOKS` 中字母开头的 22 个（其中 `eof`、`type` 按参考映射为 `id`）；
- `TYPEKW` 的 18 个（→ `type`）；
- 跳过带括号参数的 3 个、直接丢弃的 8 个（`__extension__` 等）；
- 前缀 `L u U u8`。

前缀闭包 235 个结点 + “非关键字”结点 `ID*` = 236 个状态，占全部状态的 70%、
稀疏编码的大部分（每个结点对 63 个续字符 + `\` 各有一条转移）。名字结束时
（下一个字节不是续字符）结点直接决定发什么：`if\n`、`type\n`、`id=`+拼写，或进入
字符串/字符常量/跳过。

**生成时顺带暴露的参考行为**（不是 E1 引入的，E1 忠实复现）：参考用
`vfind(TOKV, 拼写)` 定种类，只把 0（`eof`）和 1（`type`）改回 `id`。所以名叫
`num`、`str` 的标识符被发成种类 3、4：`-dump-tokens` 打出 `num=num`、`str=str`
（探针 `probes/numpunct.c` 实测）。这是参考的缺陷，归 E3 之前另行处理；E1 的判据
是与参考逐记号相同，所以不修。

## 6. 拒绝与诊断

| 情形 | 参考 | δ |
|---|---|---|
| `other` 类字节（控制字符、`@ $ \``、`\` 起首、≥128） | `err_at(i, "unexpected character")`，退出 1，stdout 为空 | `REJECT unexpected character`，位置 `i` |
| 标识符中畸形 UCN | 名字截在 `\`，`\` 再被拒 | `JUMP B` 后同上 |
| 标点首字节无匹配（`lex: stray char`） | 不可达：`OPCH` 就是由 `TOKV` 首字节构成 | 同样不可达：生成后死状态恰为 `OP:` 根 |
| 记号过多 | `MAXTOK` | 不建模 |

`reject` 时 `o` 不作为产物（§2.4），与参考“先完成词法再打印”一致。位置到
`file:line:col` 的映射由 E2 的状态决定，所以测量时由参考自己的 `err_at` 渲染
（`mkpre.sh` 的 `UA_LEXREJ` 钩子），再与参考的 stderr 逐字节比较。

**未终止的字符串/字符常量在 EOF**：参考的记号长度是 `j + 1 - start`，其中 `j = nsrc`，
所以打印会多出缓冲区之外的一个字节 `src[nsrc]`（实测为 `\0`；它是静态缓冲区中
上一轮展开留下的内容，不保证是 0）。δ 读不到 `|x|` 之外，输出到 `|x|` 为止。这是
两处已列出的不一致（§7），属参考越界读；建议的修正是让两边都拒绝，但那改的是参考，
不在本任务内。

（Python 字典上的 δ 查找），不是网络推理。参考的 `inf(S_LEX)` 那一步是模型；
在 E1 里它被展开进了表。

## 8. 转写而非推导的部分

`gen.py` 从 `lex.tsv`、`TOKS`、`TYPEKW` 推导（并断言 `TOKS == TOKV`、
`TYPEKW == TYPEV`）。以下几项在项目里**没有声明**，只写在 `lex()`/`charclass()`
的 C 代码里，所以只能转写，已在 `gen.py` 顶部集中列出：字节到 12 个类的划分、
跳过/丢弃的 GCC 词、字符串与字符前缀、`__attribute__` 前瞻的空白集合、数的扫描
规则。若要让 E1 的“推导”名副其实，下一步应把这几项作为声明放进 gold（与
`lex.tsv` 同级），由参考与生成器共同读取。

## 9. 结论

词法层在选项 A 下可以完整写成一台 δ：335 个状态，执行器只需 13 种与 C 无关的
动作，不需要字典原语，也不需要分类原语。与参考在全部 lexdiff 语料与语料库上
逐记号相同；唯一的不同来自参考读缓冲区之外的一个字节。表的主体是关键字 trie；
按本文的直接编码，稀疏约 82 KB、稠密约 342 KB。这个数字只描述词法层。
