# v0.1.3/T1.2 样本 2 操作码覆盖计划

样本固定 SHA256 `b3844c131d0f328e4aced1baae4ccc6f8ca3db7519e8a1ef58edb972948661d9`，容器 167974 B、静态 36636 条、188 函数。hello 容器独立联跑 `T14_HELLO run_rc=0 cmp_rc=0`，输出摘要 `abe3abb90b40f5ac98e27f9bb5eedfdacb673f70d11a99b72e070011f6aaf687`；此为小样本接线实证，不是样本 2 通过。

(1) 静态频表与动态里程碑分开。静态统计必须遍历裁剪后 CODE 的指令边界，不得数原始文本或在容器上数单字节。复用 `tapepack.cx:716 decode_insn`，累计 72 个桶，终点恰为 CODE 末尾、总和恰为 36636；频表按次数降序、同数按 opcode 升序，列 opcode、次数、次数/36636。现有 `--check` 只报总条数，无频表；本轮不编译，逐项次数与百分比未测。最小可执行子集须取固定输入的原生语义动态路径全体操作码；90% 里程碑取同一份动态轨迹按频次累计，不用静态频次替代，更不能让未实现指令静默跳过。先给可运行基准收全轨迹，再用汇编版对拍；正式墙钟隔离编译、重复运行并包含相同 I/O。

(2) 实现顺序及每操作码机器码估算，非实测：mov/imm/nop/exit 维持现状；2–10 整数算术、位操作 15–30 B/项；15–20 比较 18–30 B/项；27–28 直接跳转、单条件跳转 12–32 B/项，加边界共享 32–64 B；21–24、26 访存 18–45 B/项，加共享宽度/减法边界 64–128 B；29–31、37–39 调用、返回与帧参数 20–65 B/项，加共享帧管理 160–320 B；11–14 除余 20–50 B/项；43–46、32、36、40–41 宿主和参数桥 15–60 B/项，加共享分派 120–240 B；33–35 外部库边暂不估，无 ABI；48–71 浮点及转换 18–45 B/项，实测轨迹需要才补。未计分派表、对齐和扩边界的增量。已有共享库 `nm -S` 的 decode/bitmap/run 为 394/199/755 B，共 1348 B，另 `.Lshape` 72 B；距 5120 B 理论余量 3700 B，不含其他对齐或配套代码。以上不足以承诺上限，需以最终对象节和链接 map 核。

(3) 样本 2 的硬阻断不是单纯 opcode 数：HOST 段实读 exit/read/write/mmap/munmap/open/close/lseek/spawn；其中 lseek 与 spawn 不在 M1 冻结槽，执行触及时按 `fault_reason=6` 拒绝，不能擅扩，需轨迹证明未触达或选另一个不依赖草案槽的真实闭包。29–31、37–39 需补调用帧、参数传递和间接目标合同；33–35 需外部库解析；44 需六参数 ABI，并明确宿主映射地址如何与仅 DATA+BSS 可访问的线性地址模型兼容；45–46 需 argv 指针范围及字符串生命周期。FPU 的异常、转换边界按原生合同再补。没有动态轨迹前，不声称已知 90% 子集或最小成功子集；未跑真实闭包，不判 15 倍门。

(4) 量测顺序：先用同版 `tapepack --check` 核容器身份，在通过的 CODE 遍历中复用 `decode_insn` 计数；全 72 行须包含零计数项。动态统计独立记 `executed/op/count` 和 `(pc, opcode)` 首次未支持项；只拿完整运行、输出与原生 `cmp` 相等的轨迹做 90% 排序。动态短路或未支持即停的轨迹仅供排实现顺序，不作为覆盖分母。频表、轨迹与计时分别保存，计时用不带追踪的二进制。

(5) 按上界做预算：63 个新增 handler 加 `.sys` 泛化共估 2889 B（另外 33–35 尚未估），共享边界/帧/宿主 752 B；加已有 1420 B 得 5061 B，仅余 59 B，连 72 项每项 4 B 的相对跳转表都放不下。全 72 项不能据此承诺 5120 B；第一里程碑只落实测热路径子集，共享边界与帧处理，按链接后节大小记账，不为了体积删除拒绝分支。

(6) 首批回执：`tape/m0 9bb1d90690855b165e0d7b4b772fc5855729e8be`，已有 18 个操作码（新增 2–7、15–20；43 仍只实现 write）。同源 31 指令程序经 tapepack 与 `unisacc INPUT.tape -b lnx/x86_64` 分别运行，退出均为 0，stdout `cmp` 相等，SHA256 `6bfa30a3406f5226f9b24f23c30bbad3df60e97d3117a85182883f62949ea18c`。单次对拍不换算样本 2 动态覆盖；该覆盖仍未测。
