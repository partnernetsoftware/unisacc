# v0.1.3 tape M1 实测

结论：T1.4a 冻结八槽准入通过；T1.4b-lite 历史 16 对象三方等价与新语料 r1 的 16/64 对象等价通过。静默窗 r1 两档分别为 94.037 倍和 114.316 倍，未达 15 倍；102 对象外限未完成，完整等价未验证、完整倍率 UNMEASURED，正式门未通过。T1.6 未启动。

(1) 提交：`04311e839e` argc/argv；`bc5011aefd` mmap 标志；`2ee901756e` 映射边界与权限；`f8766f2601` 四种整数除法及取余；`c64252ec41` fstat 到 Linux x86_64 `sys.fs` 所用字段；`d73fbc7837` CODE 取址与间接调用；`4852f20a1a` 有界间接内存调用。cdx 独立复核除法与 fstat：同源 native/tape 均 rc=0，旧解释器分别 fault=1 与 rc=1。

(2) 已实现 40 码：0..31、37、38、42..47。其中 25 按标签区分代码与数据地址，43/44 仅接受冻结宿主槽。冻结掩码 383 不变，102 对象探针声明 exit/read/write/mmap/munmap/open/close/fstat。

(3) 以下历史对拍用 v0.1.0 固定点 g2 Linux x86_64 的 102 个对象。诊断驱动要求 `tl_dce_cut()>0`，原生三次成功，输出 9540112 B，SHA-256 `8972c2cfc069ba3d221a659d1c96100b0687dbe29b4e9c4c95a27f7507c2e76a`。tape 容器 95757 B、19557 指令、87 函数，SHA-256 `814f61fc2864dab7911d26ae1d6538c9c2a064e695df7c315e0c1ca720b1ace2`。15 亿步耗尽预算，没有全量对拍结果。

(4) 历史语料的 T1.4c 状态：UNMEASURED（负载污染）。保留原始墙钟，不据此宣称倍率或达标与否：原生 2.010 / 1.960 / 1.928 s；未插探针的 tape 33.005 s 超时，stdout 0 字节。按 cc 的同期观测，机器 load1 一度超过 20；各试次未同步采集 load1，不补写精确值。750M 步完成 7 对象，1700M 步完成 18 对象，均未进 DCE。在 716 个百万步样本中，最高频 PC 21341 仅 6 次，次高 9522、9541、9576、21338、67431 各 5 次。没有固定 PC 空转的证据。主机缺对应内核的 perf 二进制，动态原生指令数未测。

(5) 已知缺口：fstat 只投影冻结 ABI 提供且 `sys.fs` 消费的字段，不承诺完整 Linux stat。间接调用要求指令边界及 CODE relocation 入口声明。窗口内复用上次已校验的入口；冷入口线性扫描重定位。真实闭包尚无 tape 完整输出。

(6) 分级：T1.4b-lite 对 1/4/16/64 个真实对象比对裁剪前字节数和摘要、裁剪计数和裁剪后字节。直接摘取的真实对象未闭合，首片带全量外链校验时两端均退出 6；隔离实验只把合成死组的外链登记给 `tl_dce`，不宣称子集已完成最终链接。T1.4b 全量仍要求 102 对象、`tl_dce_cut()>0`、严格链接检查及 stdout 逐字节一致。两端读取同一个固定顺序清单；全量清单 SHA-256 `c3b12a4a836eded326abee6a5f9a18b87136d2f822de005748c457711a517ebe`。

(7) T1.6 尚未开工。候选设计是以现有有界解码器预构造紧凑指令记录与 CODE 偏移索引，保留逐步解码入口供状态、步骤、失败 PC 与 stdout 对拍。先用阶梯与阶段证据判断后段规模效应，再决定是否实施；15 倍门不放宽。

(8) 阶梯隔离实验：16 对象两轮 `cmp=0`，总步数 462470068，裁剪前 317638 B，`cut=199`，SHA-256 `93b5e2180cbbd49c330f17d49b1b31c7e9ba82b01eac1007e1993cfb3ede7439`。原始墙钟原生 0.082 s、tape 7.468 / 51.763 s。DCE 标记到 cut 标记（含子集摘要）135984981 步，原生相邻标记间隔 0.020311 s。64 对象原生 0.454 s，tape 首窗 55.019 s 超时，已经读完 64 对象并到 DCE 标记 1979194573 步；补测也未取得完成态。各轮 load1 未同步记录。

(9) 固定清单全量：tape 预算 30000000000 步，外层 240 秒；240.005 s 后 rc=124，无 stdout。最后标记为对象 `102`、`dce`，无 `cut`。原生同清单输出与既有 9540112 B 基线逐字相等。原生 syscall 相邻标记间隔：`102` 到 `dce` 0.001818 s，`dce` 到 `cut` 1.249195 s，`fin` 到 `out` 0.000097 s。全量停点在 `tl_dce` 与其结果检查范围内，不能归因于 `tl_finish`；未取得完整 tape 阶段步数或最终倍率。

(10) 比较限制：为使不闭合子集能隔离执行真实 DCE，子集未登记真实对象之间的外链，只登记合成死组的缺失外链；全量登记全部外链。因此阶梯不是同一未解析符号规模，不能用子集倍率外推全量。`tl_dscan` 的缺符号扫描与 `tl_dce` 的符号清理值得单独分相验证，不先开 T1.6。

(11) 最小两片也已逐字节对拍：1 对象，65403608 步，原生 0.022 s、tape 1.568 s、cut=11，SHA-256 `d5012bf62aba90e2d0661bc6efb4d83fa4bd2b05332c6aedf2790bb17d6c0d44`。4 对象，135882632 步，原生 0.033 s、tape 2.490 s、cut=42，SHA-256 `cfbb18fc18a38224fd86263abab000b320437fe840420a66594d3457c4e55772`。这些时间含启动，不能用小片倍率替代全量速度门。
