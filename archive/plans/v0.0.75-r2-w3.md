# v0.0.75 R2 一期 W3':纯链接步最小改面(设计,不改 src)

输入身份:分支 v0.0.75 头 e290a225d9;已装产品 sha16 ca84adc0fb36748a;前置度量 6aa989ba4e(release/evidence/v0.0.75-r2-proto-2026-11-18.tsv)。本文只读设计,数字凡未实测均标"推算"。

## (1) drivelink 现在重做什么,为什么

实查(src/drivelink.cx、cx/compiler/tapelink.cx、/tmp 下实编两个 -funit 对象读 ELF 头):

- -funit 对象是双载荷:真 REL 机器码(.text/.data/.bss/.rela.text/.symtab)加一节 .unisa.tape(降低前的目标中立 tape)。
- dv_link_objects 只取 .unisa.tape(tl_tape),丢掉 .text;按单元拼 tape(tl_unit 改名 __init_u -> __init_uN、源帧 id 重编号)、tl_note_links、库成员按需拉取、tl_dce(仅缺 extern 时)、tl_check_undef、查 _start、tl_finish 生成 __init 依次调 __init_u0..N,然后把整条 tape 交回 run 路,再走 tapecheck、e4、prune、lower、elf。
- 判断:重降低是实现选择(tape 跨六目标可移植、复用整程序后段),不是正确性必需。跨单元正确性真正必须的只有:全局符号解析与未定义检查、重定位、__init 顺序合成、_start 入口、目标一致、rtshared 私有流表告警。可对 -funit 对象安全跳过:tapecheck(编译时已检)、e4、prune、lower、elf 代码生成。字符串驻留与 TLS:单元对象内已定局,跨单元不合并(只损体积不损正确)。GOT/PLT:对象含 61 条 GOTPCREL、2 条 PLT32、87 条 PC32(m.o 实计),静态链接可合成本地 GOT 或把 mov 放宽成 lea,无需动态段。

## (2) 纯链接步最小改面

- 新文件 src/objlink.cx(模块 objlink,入口 ol_link(int n, const char **objs, unsigned char **exe, long *n)),只做 lnx/x86_64 REL -> ET_EXEC:合并三节、建全局符号表、按对象改名 __init_u、合成 __init 与 GOT、施三种重定位、写 ELF 头与程序头。不碰 drivelink、tapelink、整程序路。
- 接线(另一单):run 路在整程序键失且全部单元 USE35 命中或可重编时调 ol_link;任一步失败回落整程序路并打 RR_TIME route=fallback;-o 路一律仍走整程序路。
- 输入格式已足:.rela.text 与 .symtab 完整(未定义仅运行库共享名与 __init 类)。
- 产物字节与整程序路必然不同(整程序 prune/DCE 更强、布局不同),两路只比运行输出与 rc,不比字节;链接路自身两次链接 sha 必须相同。

## (3) 变参函数进闭包对象

- 现状:include/stdio.h 第 39 行 printf 为 static,由 walker 按静态格式串脱糖;cx-flat.h 的 RT_EXTERN 分支(83、360、2127、3753 行附近)只外置共享状态与三态函数,所以 m.o 182416 字节、闭包仅 27408。
- 做法:新增宏 RT_EXTERN_VA,在 RT_EXTERN 下把 vprintf/vfprintf/vsnprintf 核心改为 extern 声明,由闭包对象(-DRT_UNIT)提供全局定义;printf 等外壳仍 static 但只转调核心,walker 脱糖不受影响。
- W2 改动:tools/closure-obj.cx 的 HDRS 不变,编闭包时加 -DRT_EXTERN_VA 让核心以 .global 导出;check 加一项"用户对象不含 vfprintf 定义"。这是产品头改动,须单出补丁给集成者核。预估用户对象降到 30 KB 以下(推算)。

## 风险与回退

- 新链接器只覆盖 lnx/x86_64 与三种重定位,遇未知类型拒绝并回落;其余目标不受影响。
- 源帧 id 重编号(回溯定位)在 .text 路缺失,失败栈信息可能退化,须在 check 中显式标 UNMEASURED。
- 闭包头集合固定,超集合即回落。
- 回退:撤 W3c 接线一提交即回到整程序路,W3a/W3b 独立无副作用(W3b 未定义宏时字节不变)。
