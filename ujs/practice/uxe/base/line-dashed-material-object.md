# LineDashedMaterial 公共对象

对象在公共 Material 记录后保存 scale、dashSize、gapSize 和 sRGB 颜色。三个数值字段用 f64 保存，绘制前经 `LineDashedObject_gpuParams` 转入现有 f32 GPU 记录。设置沿用绘制参数的范围检查。GPU 绘制切片使用虚线字段和颜色，继承的透明度、深度及其它绘制状态由调用方处理。

copy 保留目标标识和事件注册表，复制公共可配置字段及虚线字段。clone 需要新标识和空的独立注册表。dispose 经公共 Material 分发事件，记录仍能继续使用，重复调用仍分发事件。

字段 JSON 包含 type、四个虚线材质字段和公共模型已支持的继承字段。读取接受 r160 的输出，缺失字段采用构造默认值，拒绝错误类型和无效字段。写入省略 UUID、名称和 metadata。共享十进制读取器对部分分数的末位舍入与浏览器不同。对拍分别固定两边的 binary64 结果，覆盖四个虚线字段与公共字段的往返。

浏览器验收独立执行 r160 构造、复制、克隆、JSON 加载和 dispose，并从克隆记录经原 GPU 桥绘制虚线。篡改只改变产品克隆的 gapSize，结构、往返和实际绘制都会发现差异。
