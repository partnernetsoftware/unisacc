# Data3DTexture 与 DataArrayTexture

当前切片借用调用者在线性内存中提供的 R8 字节。对于宽、高和深度，字节下标为 `(层 * 高 + y) * 宽 + x`。构造检查数据长度、记录对齐、内存范围及数据与记录重叠，失败时保留原记录。调用者负责在取样期间保持数据有效。

`Data3DTexture_sampleR8` 在整数 x、y 像素中心采样。第三坐标以 1/256 层为单位，0 表示首层中心，256 表示第二层中心。采样在两层之间线性插值，越过深度边缘时夹取端点。返回四舍五入后的 R8 字节。

`DataArrayTexture_sampleR8` 只取指定整数层，越界返回 -1。两个入口均检查 x、y 边界和记录种类。颜色和深度其它格式、横纵插值、mipmap、纹理上传生命周期与数组局部层更新尚未接入。

浏览器试验把线性内存中的记录和数据交给 WebGL2，使用 WebGLUtils 的 R8 三元组并上传。独立 r160 渲染器记录实际分配与上传参数。r160 构造默认使用最近邻过滤，试验显式将 3D 纹理设置为线性过滤以核对跨层插值。
