# D3 石桥上的铅笔线，桥下的水彩树

辨识度最高的是同一移动镜头里两种边缘并存。桥腹每一道砖缝都顺着拱面转弯，栏杆、窗格和阳台能逐根辨认。树冠则让大片深绿托住碎亮叶，很少给单叶勾一圈黑线。第 36 帧同时看得见这两种处理，适合作为首张验收图。

第一镜可用桥面和栏杆的视差查机位。第二镜可用车箱与远屋的尺度变化查纵深。第三镜适合查近看时砖缝、木格、藤叶还能否分开。视频能证实三种照明外观和两个剪点，光源轨迹、具体焦距、云速和草的独立摆动尚无测量。亮天小片的物种同样无法确定。

## 作者、转帖者与评论

(1) 原作者 Tsukasa Fujiwara 写的是“鉛筆線と水彩風のシェーダーテスト。”，意为测试铅笔线和水彩风格的着色器，并标了 Blender。帖子未列节点、纹理或插件名称。[作者原帖](https://x.com/TsukasaFujiwar2/status/2121969526107779526)

(2) 原帖下，danjan_design 专门提到石墙铅笔线和柔软水彩树之间的差别，ZemuDesign 关注移动时仍可读的细线。Rachel_hkz 则设想着色器若能控制线条浓淡或有助于运动画面。这是观众对可能做法的推测。[石墙与树的评论](https://x.com/danjan_design/status/2122399235190513721)、[运动与细线的评论](https://x.com/ZemuDesign/status/2122262176455098678)、[线条控制推测](https://x.com/Rachel_hkz/status/2122197034627432476)

(3) 中文转帖者黑箱之外把自由探索、昼夜变化和天气系统写成游戏设想。转帖下，Zeroltziv 说画面让人看不出是三维渲染，转帖者回复说镜头运动中仍保有手绘感最吸引他。另一条回复再次把自由走动描述成愿望。角色控制、昼夜循环及天气交互都缺少演示证据。[中文转帖](https://x.com/BeyondTheBoxCN/status/2122472282824065492)、[观众回复](https://x.com/Zeroltziv/status/2122603832383520768)、[转帖者谈镜头](https://x.com/BeyondTheBoxCN/status/2122643074841006501)、[转帖者谈探索](https://x.com/BeyondTheBoxCN/status/2122605128028938241)

## A 必须保住的效果

|效果|验收时看哪里|
|---|---|
|低机位透视、多拱的厚度与近远遮挡|第 36 帧能沿石缝看到正面转入内拱，拱洞露天。第 120 至 210 帧小车和远屋应有不同视差。把桥画成带洞立面会丢掉拱腹和透视。|
|线和色块各有职责|第 36、168、264 帧分别看亮石、灰石、暖石。砖缝、栏杆、窗格在移动时仍贴住物体；树和云用形状与亮暗交代体积。把树冠碎边全部描黑会失去远近层次。|
|光能交代材质和空间|第 36 帧验迎光石面、阴面拱腹与深树的叠放；第 168 帧验浅灰远山、暗树和一点暖窗；第 264 帧验墙上投影与深木构。并排看三帧应能从相同的屋、拱、栏杆认出同一地点。|

## B 可以后补的效果

冷镜头的漂片、最近一层草的柔焦和末镜长藤尖端的细碎变化可补气氛。第 168 帧能看到天空碎片，第 264 帧能看到藤尖轮廓；这些局部都从属于桥的尺度、石与叶的笔触差别和镜头中的空间关系。额外的昼夜或天气模拟属于转帖者设想，不计入还原分。

## 运动区域与复现假设

逐帧差图在第一镜最明显的是桥顶、树天交界和前景细杆；第二镜天空大块内部变化很小，小车边缘和孤立碎片发生变化；第三镜主要显出一条斜向的栏杆和细藤。石墙与窗框相对屋体保持位置，但随镜头整体移位。单张差图不能把植被自摆与相机视差分开。近石的细缝可逐块追踪，远石的线会合并；源帧不能证明作者采用固定像素线宽。

复现假设按可见效果选取。拱圈用实体曲面与随表面走向的砌缝，笔线可用贴体纹理或几何边，对比移动时线条是否游离。树冠用不规则覆盖形状和少量大明暗组，纸面颗粒可叠在组内。用定向光区分亮墩和暗腹，以分镜调色得到冷天和暖窗，远景减对比。原视频没有公开节点图；受光量化、投影和手画暗部的份额均待证。云和草的独立运动、体积光及具体镜头焦距也不作为首片要求。

两条观众原话分别点明 “the pencil lines on the stone wall with the soft watercolour trees” 和 “The little pencil lines really sell it.”。[石与树](https://x.com/danjan_design/status/2122399235190513721)、[移动中的线](https://x.com/ZemuDesign/status/2122262176455098678)

## 复算

将以下命令中的 ffmpeg 指向可执行文件。第一条输出 4 列 13 行的样本图，自左到右、从上到下读。第二条输出 52 条亮度差记录。第三条从全部帧定位两次硬切。

```sh
ffmpeg -v error -i /tmp/ref/d3.mp4 -vf 'select=not(mod(n\,6)),scale=240:-1,tile=4x13' -frames:v 1 -y /tmp/d3qe2-grid.jpg
ffmpeg -v error -i /tmp/ref/d3.mp4 -vf 'select=not(mod(n\,6)),signalstats,metadata=print:key=lavfi.signalstats.YDIF:file=-' -f null /dev/null
ffmpeg -v error -i /tmp/ref/d3.mp4 -vf 'signalstats,metadata=select:key=lavfi.signalstats.YDIF:value=25:function=greater,metadata=print:key=lavfi.signalstats.YDIF:file=-' -f null /dev/null
```
