# D2 水面上的距离与光

两张可用图构图和用途不同。C 是载入页的金色插画，N 是夜雨宣传卡。下面分别就每一张取证。[C 载入插画](../ref/water-keeps/c-vt20000.png)与[N 夜雨静帧](../ref/d2/frames/01.jpg)

|观察项|优先级与判定|画面证据及含义|
|---|---|---|
|镜头与层次|MUST，确定|C 从近处船板越过船头望向水道，近岸栈道斜向画内，横桥把视线截在远岸。N 从侧面看到整条小船、人物与桨。两幅各有明确视点。|
|运动与几何|MUST，不确定|C 的桥脚由水面穿起，船板随纵深收束。N 的水纹越远越密。这些是透视线索，静帧无法判定原站的网格、相机运动、视差或光学景深。|
|材质与着色|MUST，确定|C 的船板有方向性的暗缝和暖亮边，水中亮笔触碎且近宽远窄，岸草是暗色剪影；N 的水面则由亮青弧段和细雨线组成。各物体的笔触和边缘要能区分。|
|色阶、线与阴影|SHOULD，不确定|C 船板和水面各有多种渐变暖色，N 的人物靠深色块显形。两图都不足以反推固定色阶数、统一描边像素宽度、贴图来源或阴影是否烘焙。|
|照明与大气|MUST，确定|C 左侧远处最亮，其下水面有一条断续亮路；船头附近的灯和局部暖光提供近处尺度。远桥与林带在暖雾里对比收低。N 的冷水高光衬出暗船。|
|光的算法|SHOULD，不确定|C 可见亮部向邻近雾色过渡，N 可见孤立星点。不足以区分体积散射、后期辉光或直接画入插画。|
|动态|MUST，不确定|N 的雨线、水圈与桨暗示扰动；C 的破碎倒光暗示水纹。无连续画面可量倒影相位、船速、水纹传播或昼夜变化。|
|交互与 HUD|SHOULD，不确定|C 有载入提示，N 有宣传标题。两者均未展示操船、拾取、相机输入或实际游戏 HUD。|

确定，现有 UXE 可画带纹理的面和雾；已有水波形变和亮点。MUST，若重建 C 的可动视点，近船、中景桥脚与远岸须有独立空间位置；水上亮路应随观察位置、水波和亮源保持关系。现有冻结概念稿外观门只量自己的构图复现，无法给原作相似度或运动签字。反射可先用近似模型，方法待录屏检验。[现有渲染器](../../../practice/uxe/renderer-webgl.js)、[能力对标](../../../prd_uxe_sped.md)、[既有概念稿门](../look-dev/water-keeps-s0.md)

请所有者提供一段从载入进入可玩画面的连续录屏，包含静止、移动或转向、再次停住，保留水面、岸线和 HUD。以同一段影像判读视差、水光是否跟随观察角度以及玩家实际可做什么。
