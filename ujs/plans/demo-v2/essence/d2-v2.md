# D2 水面上的距离与光：原帖、成片和可玩站点

开场的金色可以换成紫蓝或雪白，船头那盏小灯、可穿行的水道、随环境而变的水中倒影仍能让人认出这段旅程。只重画载入插画会漏掉这三者在不同视点中的关系。以下优先级是对复现效果的判断，按作者预告时间复核。[作者原帖与视频](https://x.com/kevin_t_ngo/status/2119868968307695818) [640x360 原视频](https://video.twimg.com/amplify_video/2119868394363367424/vid/avc1/640x360/f5g4zXgFnuePdl3q.mp4?tag=29)

## 浏览器实际取得的公开资源

|环节|在本次部署查到的实现|与画面相连的证据|
|---|---|---|
|镜头和三维绘制|首页以 import map 和 ES 模块加载同站 Three.js。`three.core.js` 的 `REVISION` 是 `187`。`engine.js` 实例化 `WebGLRenderer` 和 60 度 `PerspectiveCamera`，近远裁面为 0.08、1800。|有真实三维视点。首页也单独列有 `opening/wide.webp`、`tall.webp`，载入图应独立对照。[首页](https://what-the-water-keeps.vercel.app/) [版本](https://what-the-water-keeps.vercel.app/vendor/three/three.core.js) [相机](https://what-the-water-keeps.vercel.app/src/engine/engine.js)|
|船与人物|`boat-hero.js` 用 `GLTFLoader.loadAsync` 加载 `boat.glb`，另载 `lantern.glb`。`rower.js` 用同一加载器载入 `rower.glb`，并导入 `SkeletonUtils`。实际下载的桨手文件为 glTF 二进制 v2，3,517,152 字节。|原站有独立三维主体、道具和材质。项目可自制几何以复现轮廓和尺度。[船](https://what-the-water-keeps.vercel.app/src/engine/boat-hero.js) [人物](https://what-the-water-keeps.vercel.app/src/engine/rower.js) [GLB](https://what-the-water-keeps.vercel.app/assets/models/life/rower.glb)|
|岸物的画感|`gouache.js` 加载重复采样的 `drybrush.webp`，共享每界灯光参数，着色器将受光变化混入分段色阶。|岸物可呈色块和干笔，换境仍能受新的光色影响。[水粉材质](https://what-the-water-keeps.vercel.app/src/engine/gouache.js)|
|水面|`water-final.js` 以镜像相机绘制平面反射，对反射作三组沿竖物投影方向的模糊采样，再以水面 `ShaderMaterial` 合成。独立扰动模拟接受船、桨和雨的输入。|竖杆、灯和天空可保持水上水下位置呼应，近浪打碎长条，粗糙度改变清晰程度。[水面与反射](https://what-the-water-keeps.vercel.app/src/engine/water-final.js) [水波模拟](https://what-the-water-keeps.vercel.app/src/engine/water-final-sim.js)|
|后处理|`post.js` 向 `EffectComposer` 依次注册场景、绘画滤镜、`UnrealBloomPass` 和最终调色。绘画滤镜由强度控制，利用深度减弱水面的滤镜作用。最终着色器含曝光、饱和、暗角、颗粒和过境雾。|岸和水可以有不同的边缘质感。注册过的效果在具体帧是否开启，要看该界参数。[后处理](https://what-the-water-keeps.vercel.app/src/engine/post.js)|

## 效果排序与静帧复查

|级别|画面效果|预告定点证据与复查方法|
|---|---|---|
|A|船、桨手与一盏暖灯形成可辨认的主体|00:12 侧看船身、桨手和弯钩灯，00:44 极光场景中仍能沿暗船轮廓找到暖灯。缩小两帧，检查是否仍可一眼找到船及朝向。|
|A|水面承接两岸竖物和主光，波纹使亮带断续|00:04 金色光源与下方亮水道相接，00:24 冷绿色厅内一排暖灯在水中成为数列短竖线。对照水线两侧的亮源位置、颜色和断续程度。|
|A|船能穿过有纵深的水道，换界会改变整个环境|00:00 横桥与近船分隔远近，00:08 红色垂挂物沿水道通向亮拱，00:16 花树横跨水面，00:36 白岸下仍是暗水与舟。复查近处遮挡、可走水口和各界的主色，而非数物件。|
|B|微粒、飘落物、星光与局部辉光|00:12 白色碎点落在花树和船之间，00:44 星空和极光拓宽上部亮区。弱化这些细点，仍应由船、岸、水光维持构图。|
