# D1 飞行的参照与证据边界

原作是 Dash 的 Forge fighterv2。现有取证读到了参数面板，浏览器抓到的游戏画布为空。下表的“确定”只用于面板文字或所有者明确指定的切片。MUST 指第一切片的必要条件，SHOULD 指后续比对项。[参数取证](../fly.md)与[所有者原话](../requirements-original.md)

|观察项|优先级与判定|依据及对第一切片的影响|
|---|---|---|
|镜头|MUST，确定|Camera 面板默认追尾，距飞机 2.6 个机长，仰高参数 12 度，飞机占屏宽 0.19。这个比例让人既读得出机身姿态，也看得到迎面而来的地形。|
|镜头运动|MUST，不确定|Camera 面板列有切换时间 1.4 秒。追尾的缓动、转弯时地平线倾角、近云与远岛的实际视差、景深均缺有效帧。不能把切换时间当追尾延迟。|
|几何与材质|MUST，确定|Sprite stack 面板列出 Jet size 0.6、Slice spacing 1、Pixel size 3。应能在滚转中读出堆叠机身的厚度和机翼。|
|表面画法|SHOULD，不确定|空白画布无法计数色阶、测描边宽度，也无法鉴别贴图来源、手绘阴影或岛屿的原始网格。|
|光与空间|MUST，确定|World 面板默认白天，岛 0.33、云 0.45、种子 7，机影开启。SHOULD，确定，Look 面板给发动机、太阳等发光值 0.8。光源方位、雾与体积光不确定。|
|动态与操控|MUST，确定|Flight 面板速度 92，按住加速乘 1.8，坡度角参数 52，指针转向。追尾视野内岛云与飞机姿态共同反馈转弯和前进。具体操作到姿态的时间曲线不确定。|
|HUD 与后续内容|MUST，确定|Helpers 面板给出右上 Tutorial、Intel 和自动触屏按钮。实际字形、准星及仪表布局不确定。SHOULD，确定，Combat、Sound 和 Camera 面板分别列出战斗、救援电台及弹射特写，属于后续切片。|

确定，UXE 已有透视相机、基本机体网格、纹理面片及跨帧状态提交的基础。MUST，首片仍要建立逐片机身、持续飞行状态和追尾镜头之间的关系。用同一段输入检查转弯、松开和加速后数帧的机身姿态及岛云相对位置。预设机形本身不能证明这些行为。[UXE 对标](../../../prd_uxe_sped.md)与[现有网格](../../../practice/uxe/meshes.js)

待补证据为正常试玩时的一段直飞、转弯并松开、掠过岛云的连续录屏，尽量保留 HUD。取得前仅能签参数和行为合同，视觉相似度待测。
