# UJS 版本计划

> 活规格：[`../prd.md`](../prd.md)  
> 产品闸：`./unisacc.com -run ujs/tests/run.cx -- --smoke|--complete`

## 规则

- **版本号**跟 **`ujs.com`**（`--version`／APE 产品名），不跟 `package.json` 的实践脊版本。
- 每版一个 `v0.0.N.md`：范围 · 完成判据 · 非目标 · 门禁。做完才开下一版文件里的「启动」段。
- 路线总表：[`roadmap-0.0.x.md`](roadmap-0.0.x.md)。
- 进度原位写回对应 `v0.0.N.md` 与 `prd.md` §0.1；不在文末追加矛盾状态。
- 纪律：产品链 **`unisacc.com` + `.cx`**；收据标签 `host1_package` / `m3_scaffold` / `method_construct` 勿混。
- 不 tip／Draft／签／公开，除非另授。
