# UJS 0.0.8 -- 切片与网落 ujs/

**前置**: 0.0.7 已交付 lex 扫描器切片(经典代码,不是 IntNet)
**状态**: 金表、网、ask、P2 包、APE `--payload` 已实跑(分支 `ujs`);host1 语义仍是 0.0.7
**产品串目标**: `ujs.com 0.0.7` 行为不变;不宣称产品推理改走网
**标签**: `method_construct`(表与网材料)。host1 仍是 `host1_package`

## 主刀

十张金表与十张网在 `ujs/weights/`。`net-gold-check.cx` 全键 ask。`pack-nets.cx` 写出 `ujs/weights/ujs-nets.pkg`(P 2 0 0 10,13218 字节)。`build-ape.cx` 已实跑:`ujs/ujs.com` 2186930 字节,尾 UNIPKG1 包长 13218 与 pkg 逐字节相同;`--version` 为 `ujs.com 0.0.7`;arith 编出 wasm。host1 仍不 ask 包内网。

超出本版产品串(仍不升版本、不宣称推理改走网):`UJS_HOST` 下 `compiler_min` 对 lex 网闸 token 类,对 parse 六 NT(top/stmt/unary/primary/postfix/pswitch)问网后按类分派;`--ask-lex` 读仓内 `lex.net.tsv`。扫描器主体仍是经典 `next()`,不是把 lex 改成 ask 网。

不把 `adapter/ujswasm/` 当产品真源。不把 archive Python 当写出者。
