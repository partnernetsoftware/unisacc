# UJS 0.0.8 -- host1 步进诚实(未交付)

**一类大改**:把「host1 能当游戏核」从默许改成合同。不升 `ujs.com` 版号直到门禁绿。

## 设计问题(证据)

(1) 三条面混用。`ujs.com` 是 `host1_package`;Pages 步进是 `m3_scaffold`/`sim.wasm`;lex 是 `method_construct`。游戏页若只调 `main_export`,既不是 UXE Host,也不是每帧核。

(2) `run_step` 等于再调 `main`(compiler_min.cx `run_step_body` 调 func 1)。顶层 `let x = 0` 每帧清零。`host_set_global` 在 main 再跑后会被字面量覆盖。所以 fly 页上物理与 `.ujs` 金表分叉,这是产品缺陷不是 demo 偷懒。

(3) `ujs.com` 明文「not this binary: M3/compiler_core, Pages/UXE」。prd 却说玩法核应收进 `ujs.com`。日用入口与游戏入口裂开。

(4) 路线表 0.0.8+ 写成「下一张网或解析切片」,会把产品裂口推成方法弧。本版不跟那条。

## 本版必须

- 文档:本文件 + `prd.md` 0.0.8 行 + fly `DESIGN.md` 写明「金在 wasm,互动在 Host,直到步进合同」。
- 实践:共享 `practice/uxe/demo/host1-runtime.js`,fly/host1-games 不再复制 instantiate。
- 明确不做:不改 compiler_min 让 let 跨帧存活(那是下一刀,单独一类);不把扫描器改 ask 网;不升 0.0.8 版号。

host1 `step` 合同:main 只初始化一次;`run_step` 跑具名 `step` 或不重写 let;或 `ujs.com` 调度 M3 出 `sim.wasm`。二选一,不并行。
