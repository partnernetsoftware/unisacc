# UJS `ujs.com` —— 0.0.x 路线

**产品定位**：ujs + wasm **生产力工具**（[`../prd.md`](../prd.md) §0.1b）。  
**理论**：Paper B 对齐底层理论；A／`unisacc.com` 为派生佐证。  
**0.0.x 主题**：壳可用、子功能收敛、合同诚实；**不**在 0.0.x 宣称方法弧（m4／全表 IntNet）卸完。

## 版本表

| 版 | 必须完成（定义） | 明确不做 |
|---|---|---|
| **0.0.1** | host1：APE + 语料 28/0 + 六目标；`.cx` 产品链；`tests/ujs/run.cx` | 嵌 core；论文改口；tip |
| **0.0.2** | 生产力合同：版本串统一；身份／预言拆分（pass／refuse／archive）；CLI 日用面（help／默认路径／子命令骨架）；prd 收束 | 扩 stage0 闭包语义；m4 落地；公开 |
| **0.0.3** | 调度第一刀：至少一条实践脊路径经 `ujs.com` 子命令或明确委托（无新 Python 出货边） | 替换 M3 为 IntNet；合并 UXE 进 host1 必绿 |
| **0.0.4** | 跑／验最小面：对 host1 产物做可机读校验或 fold 子集（`.cx`）；refuse 目录进闸 | 训模型；放宽表外接受 |
| **0.0.5** | 文档／Paper B **最小补丁**：双出货脚注 + B→A 谱系一句；门禁名对齐 `tests/ujs` | 全篇重写；Draft |
| **0.0.6+** | 按债表：更多子功能收敛、跨机 APE 收据、P1 构造迁 `.cx`（可选） | 未授权公开 |

## 退出 0.0.x（暂定）

同时成立才议 0.1.x：

1. `ujs.com` 是默认日用入口（编 wasm；至少一季子功能不靠「另记品牌 CLI」）。  
2. 船闸只开 pass／refuse 合同文件；历史宽期望不可达。  
3. Paper B 活摘要与 prd §0.1b 不矛盾（最小补丁即可）。  
4. 方法弧若开做，单独 `method_construct` 收据，不挡产品版号。

## 与根仓 `plans/v0.0.4x` 的边界

根仓 0.0.43／44 是 **unisacc／`.cx` 底座**；UJS 版本债写在 **`ujs/plans/`**，不预堆进根 0.0.44。UJS 发现的底座缺陷可**登记**到根计划，但不扩大 UJS 当版范围。
