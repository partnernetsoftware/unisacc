# UJS 0.0.5 —— host1 跑面（下一刀）

**前置**：0.0.4 ✓（验面 + `ujs/tests/` 自洽 + `--verify-list`）  
**状态**：未启动 · **推荐主刀已钉**  
**产品串目标**：`ujs.com 0.0.5`  
**标签**：`host1_package`

## 一句话

在「编 → 验」之后，补上可机读的 **跑／导出调用** 最小面：pass 语料编译出的 wasm，能在纯 `.cx` 路径下被检查「可加载／必导出可调用／约定返回或副作用」，无 Node／Python。

## 为什么先跑面、不先 construct

| | 跑面 | archive 真迁切片 |
|---|---|---|
| 对 **`ujs.com` 生产力工具** | 直接补「编／验／跑」闭环 | 方法弧，收据应标 `method_construct` |
| 与 0.0.4 衔接 | 验面已有；下一步自然是执行合同 | 与 host1 日用入口正交 |
| 风险 | 需最小 wasm 解释或宿主调用面 | 易扩大成全表迁，拖版号 |

construct 续迁保留在 [`cx-migration.md`](cx-migration.md) **W1**，**不**挡 0.0.5 关闭；若本版有余力可另开 `method_construct` 小切片，但不得冒充 host1 完成。
