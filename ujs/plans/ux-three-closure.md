本报告沿用 three-inventory.tsv 的分母。全量复核依据清单证据和已知缺口记录；A、B 栏只扣除当前明确核出的重大缺口，因此全量比例列为上限。

清单口径以同名实现、独立金值或 r160 对照及篡改反例为准，三栏合计 436/444（98.2%）。全量口径只计无已知重大缺口的条目，三栏合计至多 400/444（90.1%）。

(1) C 栏扣除 DRACOLoader、KTX2Loader、GLTFExporter、OutlinePass 和 SSAOPass，具体缺口见下表。

(2) A 栏扣除三类 CompressedTexture（设备直传及 ASTC 非常色块）、MeshPhysicalMaterial（GPU 透射等）、PMREMGenerator（完整预滤链）和 ShaderLib（额外物理着色语义）。SkinnedMesh 的蒙皮绘制、Raycaster 的七类递归分派、WebGLRenderer 的上下文恢复和 RectAreaLight 的 LTC 镜面均已验收，四项已从原先的十项扣除中移出。

(3) B 栏扣除 BC7 与 BC6H 三项、PVRTC1 四项、ASTC 十四项、ETC 三项及 DisplayP3ColorSpace 一项，涉及未覆盖的解码模式、设备上传或浏览器画布读回。

(4) DXT1 RGB、DXT1 RGBA 与 DXT5 经 WebGL2 压缩上传、采样及像素读回，对照 r160 枚举和独立金值。

(5) ETC1、ETC2 RGB、ETC2 EAC RGBA 用软件像素门验收。PVRTC1 四项对照 r160 描述符以及 Khronos 的有效尺寸、块几何与字节预算。

(6) BC7 模式 6 的 RGBA8 解码通过 43 项，选择器和 P 位变异各使一项失败。BC6H 有符号与无符号模式 11 的 RGBA16F 解码通过 64 项，索引和符号格式变异各使一项失败。共用软件 mip 与快照门共 27 项通过。

Raycaster 混合对象递归门由场景准备与拾取两个模块组成，按源码与 ABI 的内容缓存，命中校验产物哈希。先创建缓存目录，设置 `UXE_RAY_DISPATCH_CACHE` 后执行 `cx ujs/tests/raycast-scene-dispatch-io.cx -- --prepare`，再运行同一命令去掉 `--prepare`。加 `--mutate` 关闭递归，期望八次命中变成零，门返回 1。

## 已知缺口与未证实项

| 项目 | 已证实 | 待证实 |
| --- | --- | --- |
| BC7 | 模式 6，含插值、裁边与拒绝不写入 | 模式 0 到 5、模式 7 与设备直传 |
| BC6H | 两种符号格式的模式 11，HDR 位模式保留 | 其他模式与设备直传 |
| PVRTC1 | 四种枚举、位深、通道、块足迹与字节预算 | 软件解码、真实扩展上的压缩上传与像素读回 |
| ETC 与 ASTC | ETC 软件解码，ASTC 14 种 LDR 常色足迹 | 压缩原样上传，ASTC 非常色块与 HDR |
| MeshPhysicalMaterial | 清漆和 Charlie 绒面直接光可软件验收。绒面强度、颜色、粗糙度及禁用分支经 UJS 计算和 WebGL 绘制，与 r160 逐像素一致。介电薄膜 Fresnel 在三档强度、四档厚度及三个入射角下全帧逐像素对照通过 | 贴图法线、间接光及 GPU 透射。透射需先绘制透射源，再按折射路径采样。现有 GPU 命令支持写入和读回渲染目标，纹理绘制命令从 Wasm 内存上传字节，尚缺以渲染目标附件作为直接采样源的合同。保留重大缺口 |
| ShaderLib | physical 程序独立于 standard。折射率、镜面颜色、镜面强度和清漆着色已在三个直接光场景与 r160 对照。关闭清漆使一个场景的 243 个 RGB 通道不同 | 同一套 physical 程序须覆盖绒面、虹彩、间接光和透射，逐分支与 r160 同场景读回并以关闭对应分支验红。保留重大缺口 |
| RectAreaLight | 两张 LTC 表共 131072 字节与 r160 一致。固定矩形灯和正向接收平面下，漫反射和金属镜面材质各四个像素与 r160 一致。交换查找表转红 | 任意光源姿态和通用 GPU 接线 |
| PMREMGenerator | 六面 16×16 纯色立方体的基础层及六个预滤层共 10752 像素对照 r160。复现顶点阶段的浮点舍入及面边插值后，首层最大通道差由 6 降至 2，首遍模糊最大差 0.623，其他层最大差 1。容差仍为 3 | 非纯色 16×16 立方体的七层图集共 10752 像素，最大通道差 1。64×32 等距柱状图转换和七层图集共 10752 像素，最大通道差 1，换错预滤层有 2096 个通道超限。32×32 和 64×64 立方体另验 16896 和 41472 像素，最大通道差均为 1。默认 sigma 的场景捕获图集验 532992 像素，最大通道差 1，换错预滤层有 107 个通道超限。场景接线仍需从通用场景树生成六视图，夹具使用独立 WebGL 捕获简单平面。实测初始 sigma=0.0045 的 532992 像素最大通道差 1，禁用初始模糊有 1846 个通道超限；其他 sigma 与 HDR 捕获待验，当前全量扣除保留 |
| WebGLRenderer | 纹理场景在真实 WebGL 上下文丢失与恢复后重建纹理、缓冲及程序。旧世代提交被拒，像素与恢复前及 r160 一致，跳过恢复绘制转红 | 通用场景资源登记 |
| SkinnedMesh | 索引位置蒙皮接场景绘制。UXE 一张材质纹理，r160 另用四张骨骼调色板纹理。位姿和计数反例各自转红 | 带法线的蒙皮及骨架资源表 |
| VideoTexture | r160 清单条目保留为缺 | 真实视频元素解码帧、刷新与渲染读回 |
| createCanvasElement | r160 清单条目保留为缺 | 真实浏览器创建画布、命名空间、上下文和绘制读回 |
| Display P3 | 色域变换 | 真实浏览器 Display P3 画布读回 |
| SMAAPass | 边缘检测、面积表采样与错索引反例。搜索纹理 2178 个红通道字节与 r160 GPU 读回一致 | 同图的完整权重目标和最终混合未验，保留部分 |
| GLTFLoader | 同一 GLB 的场景节点、属性、稀疏 UV、采样器及内嵌 PNG。PBR、蒙皮与动画另有组件门 | 完整场景的材质、蒙皮与动画装配及失败回收尚未统一验收，保留部分 |
| KTX2Loader | 原始 RGBA8 双级 mip，线性及 sRGB，交换级次反例 | Basis 转码、其他 Vulkan 格式、设备格式选择与压缩上传 |
| DRACOLoader | 顺序原始 FLOAT32 POSITION 与直存索引，错索引反例 | 压缩索引、量化属性、EdgeBreaker 与异步资源释放 |
| GLTFExporter | 单个索引网格 GLB、平移与 PBR 颜色，r160 回读与索引反例 | 多节点、纹理和动画导出 |
| OutlinePass | 深度掩模、遮挡边缘、双轴模糊、叠加与最终加色 | 自动选取对象、内部目标调度和缩放 |
| SSAOPass | 正交与限定视锥的透视场景，遮挡和无遮挡读回，翻转深度比较反例 | 通用法线、任意透视、模糊及场景合成 |
| HTMLMesh、CSS2DRenderer、CSS3DRenderer、XRButton | 4 项保留为缺 | 真实 DOM 布局与合成、HTML 纹理交互及 XR 会话读回 |

## 余项验收与停手线

| 未完成项 | 恢复验收条件 |
| --- | --- |
| 三类压缩纹理及 B 栏压缩枚举 | 对照 r160 枚举上传真实压缩块并采样。覆盖 BC7、BC6H 剩余模式、PVRTC1 解码及 ASTC 非常色与 HDR，破坏块内容或格式必须失败 |
| MeshPhysicalMaterial | 第一通道构造透射源，第二通道直接采样附件并完成折射与混合。用同一 r160 场景比较两个通道，破坏折射偏移或采样来源必须失败。补贴图法线与间接光场景 |
| PMREMGenerator | 三入口逐级覆盖整幅 cubeUV 图集。首层每通道差不超过 3，交换粗糙度级次必须失败 |
| VideoTexture、createCanvasElement、HTMLMesh、CSS2DRenderer、CSS3DRenderer、XRButton | 用真实浏览器比较刷新帧、画布读回、DOM 合成与交互或 XR 会话的对应行为 |
| Display P3 | 真实 Display P3 画布读回。与 r160 同色输入，交换输出色域必须失败 |
| SMAAPass、OutlinePass、SSAOPass | 分别验收权重与最终混合、自动选区与内部目标调度、通用透视与法线和模糊合成。错索引、错选区或反转深度必须失败 |
| GLTFLoader、GLTFExporter | 带多节点、贴图、蒙皮和动画的同一场景与 r160 双向读回。坏引用须拒绝，加载失败须释放资源 |
| KTX2Loader、DRACOLoader | 用 Basis 转码及设备格式选择、Draco 压缩索引和量化及 EdgeBreaker 的夹具与 r160 对照，损坏输入须拒绝并释放 |

当前停在物理着色和收口报告。既有通过证据绑定各自的验收场景。上述余项等待下一轮指令。

家族内部粒度和产品接线的其他限制见 [家族覆盖记录](ux-three-family-coverage.md)。当前 D1 到 D4 的迁移状态见 [工作队列](ux-three-queue.md)。
