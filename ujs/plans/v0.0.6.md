## 主刀（唯一）

**A. 日用一条链。**

0.0.5 的日用是两步：`ujs.com FILE.ujs -o OUT.wasm`，再 `ujs.com --run OUT.wasm`。  
0.0.6 收成一步：`ujs.com FILE.ujs --run` 在同一进程里编并跑，stdout 仍是 host1 JSON；`-o` 仍落 wasm。报错走 stderr，退出非 0。

不选 **B**（archive construct 真迁）：那是 `method_construct`，容易扩成全表，本版不改标签。  
不选 **C**（Paper B 改口）：文档刀，路线放在 0.0.7+，不挡本版关门。

## 可机读闸（草案）

回归（现在就能跑，0.0.5 合同）：

```bash
./unisacc.com -run ujs/tests/run.cx -- --list
./unisacc.com -run ujs/product/run-host.cx
```

空树：

```bash
find ujs \( -name '*.c' -o -name '*.py' \)
```

关门（实现 A 时新增，本计划不写该文件）：

```bash
./ujs/ujs.com --version
./unisacc.com -run ujs/product/cli-host.cx
```

`cli-host.cx` 须打印 `cli-host.cx: ok`，并覆盖 U06-CLI-01／02、U06-ERR-01、U06-HELP-01。  
它只链到已有 `ujs.com`，不转调 Python／Node。语料用 `ujs/tests/corpus/` 里一条 pass（建议 `arith.ujs` → i64 7）和 `ujs/tests/neg/` 里一条表外拒绝。
